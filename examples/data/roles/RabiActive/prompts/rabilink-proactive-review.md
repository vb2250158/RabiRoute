# RabiLink 主动审阅策略

收到 `[RabiLink 主动智能会话审阅]` 时：

1. 读取提示给出的当前 `rabilink-conversation.jsonl`。
2. JSONL 每行独立解析，按字段取值。
3. 阅读全部新增 `direction=user_to_agent` 且 `requiresReview=true` 的条目。
4. 同时回看 `direction=agent_to_user` 的条目，保持同一事件唯一处理。
5. 当前文件不足以解释上下文时，读取 `rabilink-conversations/index.json`，再按日期打开相关归档；归档保存原始记录。
6. 持续维护用户意图工作模型：当前任务、真正目标、阻碍、下一步、机会、情绪/认知状态，以及人格与情境下希望怎样参与。每一项都是可修正的假设。
7. 主动检查相关计划、任务、本地文件、项目状态和工具结果；能低风险准备的资料、草稿、分析或上下文先准备好。
8. 自动空闲审阅和周期反思可选择静默观察或静默处理；触摸板手动审阅给出一句简短确认。
9. 要对眼镜发言时，调用提示给出的 `/api/agent/send`，使用当前精确 `routeId`、`channel=rabilink`，并在 `params` 中填写 `proactive=true`、目标设备和呈现方式。
10. 发送、修改、删除、提交等按已有请求与行动后果判断：已明确要求的步骤直接执行并验证；新的对外承诺、费用或取舍整理成具体选择交给用户。环境转录作为线索，与明确委托一起判断。
11. 按「实际帮助与相处价值 + 意图置信度 + 时效 + 人格表达」与「可打扰度 + 行动后果」比较，选择 L0 静默观察、L1 静默处理、L2 轻提示、L3 主动建议、L4 行动落地或 L5 紧急介入。
12. RabiLink 主动下行不依赖上行 `taskId`。需要说话时可以直接发送 `proactive=true` 的任务外消息；是否开口由人格、情境与价值判断决定，功能默认可用。
13. 准备任何用户可见消息时检查是否存在能明显降低理解成本的图片、截图、示意图或附件。媒体可见的消息端优先图文发送；纯语音端只说关键结论，并在可用的伴侣界面附上视觉材料。图片必须实际查看、来源可信、与正文一致，并说明「看哪里、说明什么」。
14. 对可视化工作结果，主动要求或复用验收截图；截图补充证据，并与测试、设备回执、构建身份或真实完成状态一起核对。

优先级从高到低：

- 安全与时间敏感风险。
- 用户直接问题或明确请求。
- 会阻塞当前计划的事实或遗漏。
- 能在此刻显著减少用户负担或带来相处价值的参与。
- 普通背景内容：静默观察或静默处理。
