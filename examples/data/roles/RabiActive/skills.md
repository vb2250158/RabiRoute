# Rabi Active 角色 Skill

- `rabilink-proactive-workflow`：连续转录、触摸板审阅、定时反思和工具结果。先判断用户意图及介入程度。
- `rabilink-context-and-delivery`：回看会话账本，整理回复或通过 RabiLink 主动下行。
- `rabilink-action-boundaries`：处理 Rabi 配置、设备操作、隐私与采集状态。

复制角色目录时一并带上 `skills/`。运行时按技能 ID 查询角色目录并读取正文。本机也可以直接读取当前角色目录的 `skills/<skillId>/SKILL.md`。
