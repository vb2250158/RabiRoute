# Agent software artwork

These original software icons identify the Agent that owns a conversation or sent a message. They are served from the installed Web bundle, without requests to the vendor at viewing time. Artwork is displayed with its original proportions and colors.

| Asset | Source |
| --- | --- |
| codex.png | Icon resource 0 of the installed OpenAI Codex desktop executable, version 26.1027.6604.0; extracted at 128 px. |
| workbuddy.png | Icon resource 0 of the installed WorkBuddy AI executable, version 5.9.4; extracted at 128 px. |
| antigravity.png | Icon resource 0 of the installed Antigravity executable, version 2.23.1; extracted at 128 px. |
| dsh.png | Existing DeepSeek Harness desktop artwork, `apps/desktop/resources/icon.png`. |
| copilot.svg | GitHub's official [Octicons Copilot icon](https://github.com/primer/octicons/blob/main/icons/copilot-24.svg), MIT licensed. See `LICENSE-copilot`. |
| marvis.ico | [Marvis official website favicon](https://marvis.qq.com/favicon.ico). |
| astrbot.svg | [AstrBot official dashboard favicon](https://github.com/AstrBotDevs/AstrBot/blob/master/dashboard/public/favicon.svg). |
| grok.jpg | Grok's published App Store icon, retrieved from [Apple's application metadata](https://itunes.apple.com/lookup?id=6670324846&country=us). |

The owning Agent Web entry supplies the asset URL through its trusted renderer registration. Other Agent plugins may supply their own artwork through the same optional field. Provider identifiers determine the icon; titles and message text do not. Software artwork does not identify an individual person or imply a delivery receipt.
