RabiRoute 把 QQ、微信、企业微信、飞书的消息接给你已经在跑的 Agent。不是每句话新开一个会话——是投进桌面上那个任务里，上下文还在。 RabiRoute routes chat messages from QQ, WeChat, WeCom and Feishu into the agent task you already have running. Not a fresh session per message — the same task, the same context.

一条消息怎么变成结果From message to result

RabiRoute 只负责连接和路由。模型、工具、执行都在你的 Agent 那边——所以换模型不用改网关。RabiRoute connects and routes. The model, the tools and the execution stay with your agent — swapping models does not touch the gateway.

01

消息进来Message arrives

群里的一句话、一条定时任务、一次桌面截图，都会先落成一条可查的事件记录。A chat line, a schedule tick or a desktop capture lands as a recorded event first.

02

路由挑角色Route picks a role

按你配的规则选角色、挑一个已经存在的 Agent 任务，再把最近上下文一起带过去。Rules select the role and a specific existing agent task, then attach recent context.

03

结果按规则回传Reply with rules

发送是独立动作：过发送规则、写回执。哪些话该发、发到哪，都由你定。Sending is its own step: apply sending rules, record a receipt. You decide what goes where.
