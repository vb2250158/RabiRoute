# 气泡纹理

`bubble-cat-paw-body-v2.png` 是 imagegen 生成的透明 RGBA 框体，1254 × 1254，不含尖角、文字或控件。原始 v1 素材保留供追溯，运行时使用 v2。

读取中央连续不透明区域作为框体，排除原图透明留白。九宫格以框体宽度的 25%、65%，高度的 24%、72% 切分；目标左边 40 px、右边 84 px、顶部 28 px、底部 50 px 固定。四角与右下猫爪不随正文长度缩放，中间和边条拉伸。

尖角由 Qt 独立绘制，预留 14 px，指向桌宠可见轮廓的横向中心。框体遇屏幕边缘时限制在可用区域内，尖角横向锚点继续对准桌宠；顶部空间不足时气泡放到桌宠下方，尖角朝上，猫爪仍在框体右下角。

生成工具为内置 imagegen，编辑提示词保存在 `bubble-cat-paw-body-v2.prompt.json`。资源以原始透明度保存，无图片后期修改。替换素材时使用新版本文件名，并核对切分坐标、透明边缘、短长文本及尖角接缝。
