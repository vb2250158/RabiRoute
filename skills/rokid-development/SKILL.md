# 乐奇开发与验收

## 先读

1. 阅读 [接入依据与排障](../../docs/rokid-development.md)，区分官方说明、项目约束、历史结果和本次实测。
2. 录像任务阅读 [离线录像](../../docs/rabilink-offline-recording.md)；旧语音问题按该文档的历史资料入口按需读取。
3. 核对当前源码、设备和构建；旧成功记录不能替代当前验收。
4. AIUI 对话或页面任务先读[当前对话与语音核对](../../apps/rabilink-aiui/docs/aiui-voice-current.md)和官方 [aiui-dev Skill](https://github.com/yodaos-project/AIUI/blob/main/skills/aiui-dev/SKILL.md)，按其索引读取所需 API、事件与交付检查表。分别记录官方文档提交、npm 工具版本和设备运行时；文档存在差异时列出来源，并用匹配版本与实际宿主验证。

## 路线边界

AIUI 官方 Skill 的项目入口是 `apps/rabilink-aiui/.agents/skills/aiui-dev/SKILL.md`；读取本地完整版本并运行 `npm run check:skill`，联网更新时按官方 GitHub 当前提交校验整个目录。不要把全局 `rokid-rabilink-plugin` 的历史两工具流程当作 AIUI 页面规范。

- 本项目当前不采用 CXR-M；商务授权不是待补凭证，不索要 CLIENT_SECRET 或 `.lc` 来继续本路线。
- 手机侧采用 CXR-L，经乐奇 App 控制眼镜。自有眼镜应用需核实官方眼镜端开发资料与具体设备支持。
- CXR-L 有音频不等于有连续视频接口；照片不等于视频，原生直播入口也不等于公开启动 API。
- CXR-S、Android Camera2、Glass3 SDK、RokidAiSdk 分别核实；不能因名称相似或依赖能编译就推断可用。
- 社区源码只能生成待检验的假设，不能作为官方能力或本机成功的证据。

## 官方资料

- 从官方开放平台和用户提供的精确文档开始，记录页面标题、版本、日期及支持的设备。
- 动态页面只有 HTML 外壳时，不称为已读正文；无法访问时明确记录缺失内容。
- 本项目已记录两份官方文档的公开正文入口及章节 ID，见接入文档；工具失败时先核对该入口，遇到鉴权或禁用状态停止。
- 不绕过访问限制，不把搜索摘要、镜像或社区转述标成官方正文。
- 需要的安装、签名、权限、固件及网络前置条件核清后，再选最小实验。

## 安装与失败定位

1. 确认目标手机序列号、当前前台页、眼镜连接和设备型号；不要在日志中重复 token、设备标识或推流密钥。
2. 分别确认 CXR 服务、眼镜蓝牙、CUSTOMAPP 会话以及目标包名；系统蓝牙配对不代表 SDK 通道可用。
3. 检查 APK 包名、版本、minSdk、ABI、证书摘要、文件哈希和体积；手机包与眼镜包分开检查。
4. 使用 SDK 正式安装与查询接口；分别保留安装回调、启动回调、眼镜应用回包及媒体首帧。
5. `onInstallAppResult=false` 仅表示安装失败；没有 PackageInstaller 原因时不得断言签名错误。一次只改变一个有证据支持的条件。
6. 优先正确签名覆盖安装，保留数据；安装授权不包含卸载或清空数据授权。只处理用户点名的凭据位置，保持忽略上传。
7. 重复失败后增加能区分传输与安装阶段的证据，不盲目换包名、降版本、加依赖或改签名。

## 已核实的官方前置条件

- 用户指定的[眼镜端开发环境 / 开启 ADB](https://custom.rokid.com/prod/rokid_web/84feb39f8ef141b0ad0326f902ab881f/pc/cn/3b63d21420e645e3affca478b39e4a13.html?documentId=b6c111c9eb364f4ebb68d6c76276b4b0)为固定参考入口。先排查手机 CXR-L 安装与联调，不把专用开发线列为无线安装前提；需要系统日志时再补充眼镜 ADB。

- 裸机文档支持 YodaOS-Sprite / Android 12 上的普通 Android 应用和 CameraX 录像；远程 CustomApp 需眼镜 CXR-S 与手机 CXR-L 配对。
- USB 调试使用专用开发线，并在 Rokid AI App 开启眼镜 ADB。不能推断为 CXR-L 无线安装或日常推流必须插线。
- 裸机 Sample 的 minSdk 31 / targetSdk 36 与 CXR-S 库的 minSdk ≥ 28 是不同层级约束；示例版本差异不能直接判为安装失败原因。
- CustomApp 指令须等 onOpenAppResult(true) / onGlassAppResume(true)；核对包名、入口和最新安装状态，手机缓存不代替安装查询。
- 官方裸机录像 Sample 默认无音轨；有声录像须另验音频采集与混流。CameraX 保存完成以 Finalize 无错误为准。

## 录像与验收

- 手机本地接收器拥有录像状态；启动命令成功、眼镜宣称推流均不能冒充手机收到视频。
- 视频录像包含声音，与独立录音互斥；暂停、录音、视频录像是三种互斥模式，来源选择另行处理。
- 网络离线指无互联网但仍有局域网。验证手机热点、同 Wi-Fi、断外网重新开播；不默认借服务器或 TURN 承担带宽。
- 预览静音不等于录制无音轨。保留真实媒体文件的音视频轨道、时长、完整解码与手机回放证据。
- 检查停止、权限拒绝、控制断连、接收器退出、空间不足以及重启行为，确保相机和麦克风释放。
- 延迟区分采集、编码、传输、接收缓存、解码和显示；毫秒级结论需要共同时间基准与测量误差。
- 运行改动对应测试和 Android 构建；根构建按项目要求并与其他任务协调。Android 调试不擅自切换 Host。
- 同步中文与英文文档；只报告实测层级，实验实现、安装受阻、未验收须明确标注。
