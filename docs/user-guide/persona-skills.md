# 查看角色技能

[English](persona-skills_en.md) | 简体中文

在已绑定人格的路线中打开“知识”页，点击“角色技能”。目录显示该人格保存的 Skill 标题和摘要，选择一项可阅读正文。正文作为纯文本展示，不执行 HTML。

这是只读资源目录，**不代表当前 Agent 已加载这些技能**，也不是安装、启停或编辑入口。资料中的 `active`、`draft`、`archived` 是资料状态，不是执行端加载状态。

手机可以在 Relay 管理页登录、选择归属自己的目标电脑，再进入该电脑 WebGUI 使用同一入口。浏览器沿用现有 Manager 远程前缀与访问权限；此功能不扩大移动 token 代理权限，也不在手机保存第二份技能真源。

目录只在打开、切换人格或手动刷新时读取。切换人格会清除旧详情，并忽略旧请求的迟到结果。目录为空表示没有返回可读技能；读取失败会明确提示，不能视为空目录。失败后可刷新目录或重新选择技能。

当前为源码实现与隔离客户端测试；完整构建、安装版页面、浅色/深色及手机真机验收应由发布流程另行确认。
