# プラグインの管理

サイドバー下部の「プラグイン」を選択します。一覧には設定済みプラグインの名前、用途、バージョン、実行状態、有効化スイッチが表示されます。検索や状態で絞り込み、項目を選択すると詳細を確認できます。

スイッチは希望する有効化状態を表し、「実行中」「起動失敗」「依存関係待ち」「停止を未確認」は実際の実行結果を表します。変更後に結果を再取得します。結果が未確認の場合は更新して元の操作の状態を確認し、確認のためにスイッチを繰り返し切り替えないでください。

QQ / NapCat、WeCom、Weixin、Feishu、汎用 Webhook、定期トリガー、モバイル、音声入力、Xiaomi Home はそれぞれ独立したプラグインです。ロールの入力追加メニューは使用可能なプラグインから生成されます。無効にした入力の設定は保持され、使用不可と表示されます。再度有効にすると継続して利用できます。最後の入力を削除すると空の一覧になり、QQ は自動追加されません。

「音声サービス」は認識、合成、再生、モデル管理の共有機能を提供します。「音声入力」は購読するロールに文字起こしを送信します。音声入力のみを無効にした場合、他の機能は引き続き音声サービスを使用できます。モバイル入力と PC 間接続の共有トランスポートも別々に管理します。

音声サービスを無効にすると、本アプリの接続と本アプリが管理するローカルプロセスを解放します。外部の音声サービスは停止しません。管理対象プロセスの停止を確認できない場合は、その理由が表示されます。

起動失敗や依存関係の不足は、そのプラグインの詳細で原因を確認します。無関係なプラグインと管理ページは利用できます。基本の管理画面、プラグイン一覧、アプリケーションの識別情報はアプリケーションが保持するため、業務コアを無効にした後もプラグイン画面から再度有効にできます。

プラグインのスイッチとロールの入力設定は別々に保存します。スイッチは即時送信され、ロール設定は従来の「保存」ボタンを使用します。一覧に認証情報は表示しません。診断用のプラグインとインスタンスの識別子は詳細で確認できます。

ロール設定を保存すると、設定の保存、実行環境への適用、一部入力の使用不可を分けて表示します。入力の接続設定だけを変更した場合は、その影響を受ける入力を更新します。共有の識別情報、Agent の対象、メッセージ処理の変更には、ゲートウェイの通常のライフサイクルを使用します。未確認の保存結果は元の操作に照会し、その後の編集内容は保持します。

本ページはソース実装の操作を説明しています。インストール済みバージョンと受け入れ確認の範囲は別途確認してください。ソースのビルド成功だけでは稼働中サービスは更新されません。
