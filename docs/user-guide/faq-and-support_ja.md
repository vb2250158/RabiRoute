# よくある質問とサポート

このページは、最初に使用する一般的な質問に答え、保守者がすぐに再現できるレポート形式を提供します。

## 最初にQQを設定する必要がありますか?

いいえ。最初にスケジュールされたトリガーとCodexを実行し、次に NapCat を追加します。これにより、ハンドラー配信の問題と QQ ログインの問題が分離されます。

## マネージャーが接続されました。なぜ配信がないのですか?

マネージャ接続は、WebGUI がコントロール プレーンに到達できることを意味するだけです。ルート ランタイム、メッセージ接続、ルールの一致、およびハンドラー バインディングを個別に確認します。

## なぜ通常のグループメッセージが無視されるのでしょうか?

アンビエントグループメッセージは無条件に転送されるわけではない。追加 `group_message` 焦点を当てた正規表現を使用したルール。メンション、返信チェーン、およびプライベート メッセージは、独自のルートの種類を使用します。

## なぜ保存は外部システムを変更しなかったのでしょうか?

未保存の通知が消えたことを確認します。一部の変更ではルートを同期またはリロードしますが、NapCat、WeCom、または Relay 設定もそのプラットフォームでアクティブになる必要があります。

## 名前が変更されたCodexタスクが依然としてメッセージを受信するのはなぜでしょうか?

RabiRouteは、安定したタスク識別子として完全なCodexタスクIDを使用し、現在のターンに構成されたワークスペースを使用する。別の保存済みデフォルト cwd、名前変更、または完了した目標によっても、タスクは無効になりません。

## なぜタスクは異なるモデルまたはツールセットを使用するのでしょうか?

Codexデスクトップタスクは、そのモデル、ツール、サンドボックス、および承認を所有する。 RabiRoute 互換性フィールドはこれらの設定をオーバーライドしません。

## はどこにありますか `draft` 承認を待ちますか?

現在、汎用のWebGUI承認キューは存在しない。 `draft` は、送信ボックスの結果と監査ペイロードです。データとログを検査し、明示的なビジネス プロセスに従います。

## 手動トリガーは安全ですか?

これは、制御された検証には役立ちますが、副作用のないプレビューではありません。ログを書き込み、AgentPacket を構築し、実際のハンドラーの配信を開始します。

## 全体を添付できますか? `data/` ディレクトリ?

いいえ、実際のメッセージ、アカウント、トークン、タスクコンテキスト、およびプライベートパスを含めることができます。サニタイズ後に最小限の現在の実行ログを提供します。

## 現在のバージョンはどこにありますか?

サイドバーのブランド領域には、実行中のバージョンが表示される。ルートを検査することもできます `package.json`。ソース、パッケージ、またはトレイ ランチャーを使用したかどうかを報告します。

## 報告前の最小限のチェック

1. 現在のバージョン、Host の状態、対象 Route のログを記録します。更新が必要な場合は正式な更新手順を使用します。
2. いくつかの実験入力の代わりに、1 つの最小限のルートで再現します。
3. 現在の起動時間と最初のエラーを記録します。
4. メッセージレコード、AgentPacket、およびOutboxの結果を個別にチェックする。
5. アイデンティティ、トークン、クッキー、プライベートチャット、およびプライベート絶対パスを削除する。

![An example Log diagnostics screenshot without accounts, tokens, or private messages](../../assets/screenshots/webgui-diagnostics-en.png)

共有する前に、自分のスクリーンショットを確認してください。実際のルート名、アカウント、タスク名、絶対パス、メッセージ テキストが表示される場合は、それらをトリミングまたはカバーします。

## 助けを求める

- このガイドとさらに詳しい内容を検索してください [トラブルシューティング ガイド](../troubleshooting_en.md) まず。
- 小切手 [現在の能力と成熟度](../current-capabilities_ja.md) 計画された機能をバグとして扱う前に。
- 再現可能なバグやドキュメントの問題を報告してください。 [GitHub の問題](https://github.com/vb2250158/RabiRoute/issues).
- コード拡張の場合は、次の部分から始めます。 [開発者ドキュメントのインデックス](../README_ja.md).

セキュリティレポートでは、認証情報、アカウントデータ、または悪用可能な詳細を公開しないでください。リポジトリが提供するプライベート セキュリティ チャネルを使用します。何もリストされていない場合は、機密情報を明らかにせずに、まず質問してください。
