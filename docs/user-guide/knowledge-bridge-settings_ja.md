# 接続後のナレッジサービスの使用



RabiLink設定でアプリケーションを接続し、そのナレッジツールを使用するオンラインPCを選択する。同じアプリケーション内の認証されたデバイスは、MCP アドレス、ナレッジ シークレット、ペルソナ/ツールのホワイトリスト、またはデバイス許可 JSON なしで、デフォルトで読み取りと書き込みができます。

音声アドレスは高度な接続パラメータのままです。別の許可を追加するのではなく、ローカル サービスを選択します。オフラインのデバイス、互換性のないバージョン、または停止したサービスについては、対応するステータスを検査してください。助成金を再入力しても、サービスの可用性を修復することはできません。資格情報が取り消されたり、再バインドされたりすると、古い ID でリクエストを続行できなくなります。

書き込みが不確実な場合、元の操作キーを保存し、自動再生せずに受信を問い合わせます。アプリケーションの接続、サービスの準備状況、ビジネス書き込みの成功は別個の結果です。古い許可フォームは削除されました。構成の正規化/保存では、他の設定とデータを保持しながら、廃止されたフィールドが削除されます。統一された動作を実現するには、PC と Relay の両方を更新する必要があります。
