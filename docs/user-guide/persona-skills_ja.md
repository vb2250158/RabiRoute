# ペルソナスキルの表示



「計画・メモリ」でペルソナを選びます。ルートへの関連付けは不要です。選択する項目は **ペルソナスキル**。カタログには、保存されたスキルのタイトルと概要が表示されます。項目を選択すると、その本文がプレーンテキストとして読み取られます。 HTML は決して実行されません。

これは読み取り専用のリソースカタログです。 **現在のエージェントがこれらのスキルをロードしているという証拠ではありません**。スキルのインストール、有効化、無効化、編集は行われません。 `active`, `draft` そして `archived` 実行ホストの読み込みステータスではなく、リソースのメタデータを記述します。

電話機で、Relay Management にサインインし、そのアカウントが所有するコンピュータを選択し、その WebGUI を開いて同じエントリを使用します。リクエストでは、既存の Manager リモート プレフィックスと承認が保持されます。この機能は、モバイル トークン プロキシ権限を拡張したり、電話機に 2 番目のスキル権限を作成したりすることはありません。

カタログは、開くとき、ペルソナの変更時、および明示的なリフレッシュ時にのみロードされる。ペルソナを変更すると、以前の詳細が明確になり、遅れた応答が破棄されます。空のカタログは、読み取り可能なスキルが返されなかったことを意味します。失敗は個別に表示されます。カタログを更新するか、スキルを再度選択して再試行してください。

これは、分離されたクライアントテストを伴うソース実装である。完全なビルド、インストール済みページのチェック、ライト/ダーク テーマ、およびモバイル デバイスの受け入れは、リリース時に個別に検証する必要があります。
