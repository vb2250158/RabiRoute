# 连接后使用知识服务

[English](knowledge-bridge-settings_en.md) | 简体中文

在 RabiLink 配置页连接应用，再选择已上线的目标电脑，即可使用它提供的知识工具。已鉴权且属于同一应用的设备默认允许读取和写入，无需填写 MCP 地址、知识密钥、角色与工具白名单或设备授权 JSON。

语音地址仍可在高级连接参数中配置；它决定使用哪个本机服务，不是另一层权限。设备离线、版本不兼容或服务未启动时检查对应状态，不能通过重复填写授权解决。已有应用凭据被撤销或设备改绑后，原请求不能继续沿旧身份执行。

写入失败且结果不确定时，保留原操作键查询回执，不自动重试。应用连接、服务就绪和实际写入成功是三项不同结果。旧权限表单已删除；保存或升级后的配置归一化会移除旧权限字段，其它配置与数据保留。PC 和 Relay 均需新版才能统一此行为。
