# 本机知识桥安全设置

[English](knowledge-bridge-settings_en.md) | 简体中文

在 RabiLink 的本机设置页展开“本机知识 MCP 安全设置”，先读取配置，再填写已运行的本机 MCP 地址、角色与工具白名单及设备归属授权。该入口沿用本机或已认证远程 WebGUI 管理权限，不开放设备通用代理，也不会启动服务或执行知识业务。

密钥只通过密码输入框写入，永不读回；已配置时留空保留，掩码不作为密钥提交。不在手机设备 profile 或 Relay 配置中保存本机连接密钥。写权限默认关闭，近期记忆详情的阅读标记也受写权限限制。

保存只 PATCH `rabiLinkRelay.knowledgeBridge`，不替换其他 Relay 设置。保存后核对权威配置；结果不确定时暂停再次保存，要求用户刷新检查。现有 identity API 没有配置 revision CAS，因此不宣称多管理员并发安全；刷新会覆盖未保存编辑。密钥只能核实 PATCH 成功且已配置，不能通过读回验证原文。超时后的刷新不证明本次密钥已写入，应明确核对后再作新的管理决定。

“已保存”与“知识桥就绪”分开。刷新读取真实 runtime `knowledgeBridgeReady` 和能力目录；就绪表示预检成功，仍不代替实际工具调用。设备的 Relay 授权、本机设备授权和 MCP 服务授权必须同时允许。当前实现已经过本机测试和构建，不代表安装或真机验收。
