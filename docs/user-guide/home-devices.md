# 查看设备并测试动作

打开消息路线中的“智能家居 → 米家 / Xiaomi Home → 设备列表”。每台已登记设备显示一张卡片，包括名称、房间、型号和可查询实体数量；可按名称、房间或型号搜索。场景及没有设备归属的辅助实体单独显示。

打开设备卡片会记录使用次数。下次刷新页面或点击“刷新设备”时，打开次数多的设备排在前面；次数相同按最近打开时间排序，其余保持原顺序。当前列表不会在点击后立即跳动。记录保存在当前浏览器，清除网站数据会重置排序；场景与辅助实体不计入。

1. 点击设备卡片，选择要查询或控制的项，查看当前状态和 Agent 能力。
2. 选择已公布动作，按参数规范填写 JSON。数值、布尔值和数组保持原类型；不知道专用字符串协议时不要填写猜测值。
3. 点击“预演参数”只验证参数，不操作设备。点击“执行测试”才发送动作。
4. 执行后查看结果，必要时点击“查询原回执”及“查询最新状态”。服务受理不等于物理动作已经完成。结果未知时页面只查询原回执，不重复发送；最近回执保存在当前浏览器，刷新页面可继续查询。

扫地机详情另有“地图与位置”：支持 version-2 云地图显示和5/10/30秒快照刷新。隐藏页面、关闭详情或切换页签会暂停读取。连续三次失败停止自动刷新，保留最后地图。更新时间表示文件下载；位置即时性未验证，文件和轨迹位置均不变时不重绘。

地图和 Agent 现在共用地图／轨迹反馈接口。能取得轨迹尾点时，橙色标记显示“轨迹位置”；页面说明本轮有没有新增轨迹点。没有有效轨迹时显示云地图快照，并说明原因。地图不变但轨迹位置变化时更新标记；重复返回旧点不会算作再次移动。切换设备或机器人任务后重新建立游标。读取时间仍不代表设备定位时间，这项反馈尚不能证明到达或启用自动寻路。

地图默认按窗口宽度和高度完整显示，使用“放大”“缩小”查看细节，“适应窗口”恢复全图。放大后可滚动查看；地图详情与原始文件默认折叠。缩放不改变选点的原始地图坐标。

地图右下角提供紧凑的 16:9 视频小窗，播放时默认只显示画面。点击画面显示画面内的状态、刷新和“退出视频”操作，再次点击或按 Esc 隐藏；键盘 Tab 可聚焦画面，Enter 或空格切换操作层。显示或隐藏操作不打断播放。较窄的地图使用更小的预览；手机等很窄的窗口将小窗靠右排在地图下方，避免遮住选点区域。密码管理时完整显示表单，沿用页面浅色和深色主题；窄屏设备下拉框随宽度收缩，避免横向溢出。需要密码时，输入米家中已有的四位视频密码，再点击“开启视频”；输入掩码显示，可切换可见，提交后清空。勾选“记住密码（本机）”后，设备确认正确才加密保存。已保存时默认显示“密码已保存”和连接按钮，不再展开密码输入框。

提交连接、等待画面和播放期间隐藏密码输入、更换及删除入口；点击“退出视频”，本次退出回执确认后才恢复密码管理。退出未确认会保留会话和错误提示，不提前开放删除。退出后点击“管理密码”可更换或删除本机保存的密码，不修改设备密码。连接失败时先退出，再重试或核对密码；收到真实首帧并播放后，操作层显示“实时画面”。首次使用需安装[视频传输组件](../vacuum-cloud-map.md)。视频不收音、不录制、不移动；不设播放时长上限，关闭详情、切换页签或隐藏页面时停止。摄像头开关状态仍每5秒查询，可在操作层手动刷新；开关开启或正在连接不代表已经收到画面。

视频连接超时或不可达时，预览窗显示连接原因。电脑位于上级路由器等不同网段时，CS2 传输会在小米云提供有效参数时尝试实验性中继，并显示连接方式；仍须以收到真实画面判断成功。中继失败会区分发现、注册、端口分配或设备加入阶段。局域网连接失败且电脑没有同网段接口时，显示扫地机地址与网络检查提示；可将电脑接到扫地机所在路由器的 LAN 口或 Wi-Fi。功能不修改网络配置，同网段也不保证视频可达。设备查询和控制继续使用 Home Assistant，地图与视频是额外的米家云能力。

点击地图选择坐标，并以蓝色虚线预览路径；墙、禁行区或净空不足会显示原因。地图变化后需重新选点。预览起点仍是时效未验证的云文件快照，不发送移动指令。当前没有经过验证的到点导航指令，“移动机器人到目标点”尚不可用；不能把开始清扫当作导航。已接通的开始清扫、暂停、停止、回基站等动作在“能力与测试”中使用。机器人任意播报和收音未接通。

连接完成后沿用现有鉴权，不需要逐设备批准。设备卡片只包含当前连接中有已公布实体的登记设备；禁用或没有公布实体的设备不计入此目录。初次连接见[家居接口](../home-device-agent-api.md)，地图连接见[云地图说明](../vacuum-cloud-map.md)。


地图下方新增“手动控制”：点击进入时先暂停正在进行的清扫并确认，再进入遥控。面板获得焦点后按住 W 前进、A 左转、D 右转，S 停止；松键或失焦发送停止。当前型号没有倒退指令。退出不自动恢复清扫，关闭地图退出遥控；视频延迟时同时观察设备。网页与 Agent 使用同一个[遥控接口](../home-device-agent-api.md#手动遥控webgui-与-agent-共用)。
