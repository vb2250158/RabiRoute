# インターフェーステーマ

**現在のガイド。** 設定ページ、WebGUI、トレイメニュー、ペルソナパネル、選択テキストアクションバー、およびスクリーンショットウィンドウは、同じテーマの選択を使用する。

## 使ってください

WebGUI でオプションを 1 つ選択してください **設定** ページ:

- **フォローシステム**:RabiRouteは、ブラウザとWindowsの現在の明るいまたは暗い外観に従います。
- **光**:常にライトインターフェイスを使用します。
- **ダーク**:常にダークインターフェイスを使用します。
- **カスタムテーマの追加**: 現在のテーマからすべてのパラメータをクローンし、その名前、ライト/ダークベース、セマンティックカラー、コーナー半径、表面の不透明度、シャドウを編集します。ページ、カード、および入力サーフェスは、選択した基本モードと一致する必要があります。 **保存して適用** は、すぐにアクティブにし、選択可能なテーマとして保持します。

組み込みの選択肢は、ページ保存アクションによって保持されます。カスタム テーマは直接永続化されます。 **保存して適用**。現在の WebGUI はすぐに変更されます。トレイは次回の設定更新時に (通常は 10 秒以内に) 変更され、再起動時に保存された選択内容も読み取られます。

## 唯一の真実の情報源

テーマは、次の場所に保存されているホストレベルのデスクトップ設定です。 `data/desktop/settings.json`:

```json
{
  "theme": "custom:night-rain-green",
  "webTheme": "custom:night-rain-green",
  "customThemes": [
    {
      "id": "custom:night-rain-green",
      "name": "Night Rain Green",
      "baseTheme": "dark",
      "colors": { "success": "#16a34a" },
      "styles": { "cornerRadius": 8, "shadow": "soft", "glassOpacity": 94 }
    }
  ]
}
```

`theme` デスクトップ互換の選択内容を保存します。 `webTheme` WebGUI選択を格納し、信頼できるWeb専用プラグインテーマを参照することもできる。なしの古い設定 `webTheme` 継承する `theme`;ぶら下がっている `custom:*` 値は、利用可能なテーマにフォールバックします。マネージャーの `GET` そして `PATCH /api/desktop/settings` は、WebGUI と Windows デスクトップの共通インターフェイスです。従来のブラウザ キーは一度移行されて削除されるため、信頼できる 2 番目の情報源になることはできません。

## モジュールの責任

|モジュール |責任 |
| --- | --- |
| `src/shared/interfaceThemeContract.ts` そして `desktopSettingsContract.ts` |組み込みテンプレート、カスタム フィールドと境界、選択したテーマ、入力検証。 |
|マネージャー |ホスト設定を読み書きし、それを返します。 `/api/desktop/settings`. |
| WebGUI |組み込みの CSS トークンと Vuetify パレットをロードします。 `ribiwebgui/src/themes/light/` または `dark/`;カスタム テーマの CSS セマンティック トークンと Vuetify コントロール パレットの両方を更新します。ステータステキストとその意味論的表面をペアにする。そして、すべてのスイッチに、テーマが所有するオフトラック、サム、および緑色のオン状態の色を使用させるようにします。 |
| Windows トレイ |組み込みのロード元 `desktop/tray-task-window/rabiroute_tray/themes/`;同じカスタム宣言から Qt パレット、メニュー スタイルシート、および既存のウィンドウの色の置換を生成します。 |

テーマは、外観の色およびシステムの色の好みのみを制御する。ルーティング、メッセージ、プラン、権限、データ処理は変更されません。

## 検証

1. テーマを変更し、WebGUIを更新し、選択肢が残っていることを確認する。
2. トレイメニューとペルソナパネルを開きます。背景、テキスト、境界線、およびボタンは、WebGUI と同じライト モードまたはダーク モードを使用します。
3. 選択テキストメニューおよびスクリーンショット機能を有効にする。アクション バーとスクリーンショット ウィンドウはトレイのテーマに応じて変化します。
4. システムに従うを選択し、システムカラーモードを切り替え、WebGUIとトレイの両方が更新されることを確認する。
5. 異なるページ上のスイッチをチェックする。オフ状態は現在のテーマに適合するが、オン状態はそのテーマによって供給される緑色を一貫して使用する。
6. 現在のテーマのクローンを作成し、成功/オンの色を変更して保存します。 WebGUI スイッチ、トレイ メニュー、ペルソナ パネルが更新されていること、および更新後もテーマが選択可能な状態のままであることを確認します。
7. 無効な色を入力するか、表面の明るさを選択した明るい/暗いベースと競合させるか、本文、見出し、または下の小さな二次テキストを減らしてください `4.5:1` をカード表面に当てます。保存は、影響を受けるフィールドに修正メッセージを表示してブロックする必要があります。
8. 成功、警告、エラー、情報、およびアクセントの状態をチェックする。テキストは、明るいテーマ、暗いテーマ、およびカスタム テーマで一致するセマンティック フォアグラウンドとサーフェスを使用する必要があります。
9. カスタムテーマが選択されている間に、設定以外のページを更新します。通常の WebGUI コンテンツと Vuetify のボタン、チップ、アラートは同じパレットを使用する必要があります。
