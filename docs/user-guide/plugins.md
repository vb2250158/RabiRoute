# 管理插件

点击左侧栏底部的「插件」。列表显示已配置插件的名称、用途、版本、运行状态和启用开关，可以搜索名称或按状态筛选；点击插件打开详情。

宿主版本显示在左侧 RabiRoute 名称下，每个插件的版本显示在插件列表和详情，彼此独立。详情中的「配置版本」是选定包，「运行版本」是实际启用的包；更新未生效时两者可以不同。

开关表示你希望启用的状态，「运行中」「启动失败」「等待依赖」「停止未确认」表示实际执行结果。修改后界面会重新读取结果。若提示结果未确认，刷新查看原操作的结果；不要反复切换来猜测是否成功。

QQ / NapCat、企业微信、个人微信、飞书、通用 Webhook、定时触发、移动端、语音消息端和米家各有独立插件。角色的「消息端」从当前可用插件生成添加菜单。插件停用后，已有消息端配置仍保留，页面显示不可用；重新启用插件后可继续使用。删除最后一个消息端会保留空列表，不会自动补回 QQ。

Codex、DSH、Copilot CLI、Marvis、AstrBot、WorkBuddy、Antigravity、Device Agent 和 Grok Bot 也分别是插件。角色中的「添加 Agent」列出当前可用端；已有 Agent 的配置与主 Agent 选择在插件关闭后仍保留，卡片会说明不可用原因。重新启用后可继续使用原目标，不会自动切换到其他会话。

Agent 扫描在进入角色配置页时执行一次，也可以显式刷新。展开卡片、编辑和保存不会重复扫描；某一端扫描失败时，其他端仍可显示结果。电脑或设备目录读取失败时，已有目标在自己的卡片查看诊断；其他来源的诊断可在「添加 Agent」查看并刷新，不影响正常本机端的编辑和保存。关闭 Agent 插件只停止本应用对该端的使用与自有资源，不会关闭外部 Codex、DSH 或其他桌面程序。

「语音服务」提供共用的识别、合成、播放和模型能力；「语音消息端」负责将转写发送到所订阅的角色。仅关闭语音消息端会停止这一入口，其他使用语音服务的功能仍可使用。手机消息入口与电脑连接的通用传输也分别管理。

停用语音服务会释放本应用的连接，并回收本应用管理的本机进程；配置的外部语音服务不会被停止。自有进程未能确认退出时，详情会保留未确认原因。

某个插件缺少依赖或启动失败时，先打开该插件详情查看原因。无依赖的插件和管理页面仍可使用。基础管理页面、插件列表及应用身份查询由应用持有；关闭业务核心插件后，仍可从插件页重新启用。

插件设置与角色消息端配置分别保存。插件页的启停立即提交；角色配置页的编辑沿用顶部「保存」。列表不显示凭据，诊断时可在详情复制插件及实例标识。

角色配置保存后，页面分别说明是否写入配置、是否已在运行端生效，以及是否有部分入口不可用。只调整某个消息端或 Agent 插件自有的连接参数时，会更新受影响的插件；普通直接投递的会话调整也可局部更新。若该主 Agent 正在使用消息处理或记忆整理 worker，调整其会话与目录会按原生命周期更新相关网关。共用身份、主 Agent 选择、共用模型、计划助手配置和消息处理流程变化也沿其真实依赖更新。结果待确认时，查询原保存结果，页面会保留你之后的新编辑。

本页描述源码实现的交互；当前安装版本与验收范围应分别核对，源码构建通过并不表示在用服务已经更新。
