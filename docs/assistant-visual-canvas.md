# 语音助手画布

助手通过 `assistant_canvas` 展示一张可更新的 16:9 画布。用户通过语音提出需求，不需要填写图表参数。画布支持组合折线、面积、柱状、散点、饼图、文本、矩形、椭圆、箭头和表格；同一画布可以包含多个图表。

`show` 用完整文档原子替换当前内容；`inspect` 读取状态；`close` 收起当前画布。`persistent: true` 保留到助手或用户关闭，后续每次模型请求都附带当前画布状态。默认临时画布在下一次通过回声过滤的非空语音文字或新文字输入出现时收起。原回复保留图表快照，关闭活动画布不删除聊天记录。清除上下文同时清除活动画布。旧回合不能在新输入后重新打开或关闭新画布。

## 三种显示方式

| 宿主 | 显示与操作 |
| --- | --- |
| WebGUI | 临时图表附在回复中；常驻图表独立悬浮，可拖动、放大和关闭。 |
| 桌面 | 图表窗口默认吸附字幕上方，跟随字幕移动；取消吸附后可独立拖动和缩放，也可重新吸附。 |
| AIUI 眼镜 | 语音主界面中央单色画布，下方保留简短字幕，无聊天输入框。 |

共享 SDK 拥有文档校验、绘制和生命周期。宿主拥有消息存储和显示窗口，不能维护另一套正式画布状态。Web/Rabi 的快照进入原有加密聊天记录；AIUI 的持久状态按当前配置作用域保存在设备存储。桌面位置仅属于窗口表现，取消吸附不改变图表内容或常驻属性。

## 文档合同

坐标以 `960×540` 逻辑空间表示，宿主等比缩放。每个节点提供 `kind,x,y,width,height`。文本建议不少于 24 逻辑像素。图表使用 `chartType,labels,series:[{name,values}]`，缺失数据用 `null`；饼图要求单个非负系列且总和大于零。`title,description,sources:[{label,url}]` 说明图表口径和来源。数据源仅作为文本链接显示，不自动请求。

例如价格走势必须先通过搜索或其他已授权工具取得实际数据，再标明日期、货币、型号和报价口径。不同日期的单次搜索报价不能伪装成连续历史趋势。不得为填满图表而编造数据。

画布接收结构化数据，不执行 HTML、JavaScript、任意组件事件或远程图片。单色系列通过线型、标记和编号区分，不能只依赖颜色。当前实现是上述明确列出的显示控件，并不声称支持 AIUI 全部交互控件或任意 A2UI 命令。
