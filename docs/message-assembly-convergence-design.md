# 消息组装收敛设计（O4，待实施）

本批只设计，不改变 `contextDetail`、路由配置或 `messageGroupPrompt`。依据 [执行方案](agent-delivery-optimization-plan.md) 与 [组装架构](message-assembly-architecture.md)。

## 目标与边界

以一份有序段落清单替代精简、详细、消息处理 Agent 三处内联段落组合。共享事实由既有数据拥有者提供；渲染不额外查询，不拥有路由或回复状态。消息处理 Agent 的调度、合并和回执合同保持独立，仅复用内容段落。

## 段落清单

| 顺序 / 段落 | compact | full | 消息处理 Agent | 启用规则 |
| --- | --- | --- | --- | --- |
| 1 消息正文 | 必须 | 必须 | 必须 | 正文只出现一次，保留原文 |
| 2 当前情况与消息身份 | 必须 | 必须 | 必须 | ID、引用、消息组有值才输出；缺少身份不阻断 |
| 3 近期情况 / 当前讨论 | 有限摘要 | 完整预算内 | 消息组范围 | 服从规则近期条数，0 不读历史；排除本组消息 |
| 4 附件 | 按需 | 按需 | 按需 | 存在附件，保留可用性和来源 ID |
| 5 消息代码与被引用内容 | 按需 | 按需 | 按需 | 只在原消息具有代码或引用证据时启用，不靠猜测补全 |
| 6 身份定位与情景 | 摘要 | 详情 | 按职责 | 本地角色或已鉴权来源可提供时；预览不写身份 |
| 7 人格、计划、记忆、技能入口 | 入口与必读 | 详情与必读 | 按职责 | 保留必读项；远端角色始终使用原来源 |
| 8 专项任务 | 按需 | 按需 | 按需 | 计划反馈、记忆整理、移动配置、陪伴等按真实事件启用 |
| 9 工具、设备与诊断入口 | 所需入口 | 详情 | 所需入口 | 按目标能力和事件依赖，不注入无关设备清单 |
| 10 回复与调度控制 | 原合同 | 原合同 | 原调度合同 | 控制块由现有拥有者提供，不能被预算裁剪 |

信封在上述内容外只包一次，统一由信封层负责；清单不渲染第二份消息源。正文、必读项、消息身份和控制块优先保留，超预算先裁剪可选详情。保留现有历史条数、截断与权限边界，不把 full 解释为无限历史。

## 清单合同与启用规则

每项定义稳定段落 ID、顺序、适用目标、模式、启用条件、预算优先级与渲染器。组装输入一次准备好 record、路由结果、知识视图、目标职责和控制块。渲染器只消费输入；禁用段落不发起查询。调度专有段落可以有独立 renderer，但不另建共享段落副本。

同一来源的引用 ID 保序去重；缺值不输出。当前实际群聊引用来自 `repliedMessageId`，`replyContext` 在面板等入口为开放对象；实施前按入口明确字段合同，不能将任意目标 `messageId` 当作被引用消息。O2 同时读取原生群聊引用与显式 replyContext 消息 ID。

## contextDetail 产品化决定

建议保留并产品化为路由可见的 `contextDetail: compact | full`，默认 compact，与当前生产行为一致；full 提供更多可选上下文而不增加权限。规则继承路由值，本轮不另加规则级覆盖。管理 API、配置校验、持久化、WebGUI 与中英文说明必须同批接通；选项旁说明更多上下文的长度成本。

运行时解析唯一有效模式后传入清单，不再保留两套业务组装器。迁移期间原调用参数作为薄适配：显式值优先，其次路由配置，再用 compact。旧函数只委托共同实现，不复制段落。消息处理 Agent 保留自身职责参数，不因 full 变为主 Agent。

若后续产品决定不提供配置，应将必要段落合入默认清单并同批移除 full 分支及仅测试调用，不能继续保留测试专用实现。该替代方案需后续任务确认，本批不执行。

## 迁移与验收

1. 固定当前三入口输出夹具，覆盖群聊、私聊、面板、计划反馈、语音、远端角色、消息组和无来源。
2. 提取纯段落 renderer 和共同输入，先迁移 compact；逐字对照正文、信封、控制块及必读项，差异逐项说明。
3. 迁移 full，再迁移消息处理 Agent 的共享段落；调度段落仍由原 owner 提供。删除已替代的重复组合逻辑。
4. 同批接通配置、API 与 UI，验证默认、显式 full、保存重读和未知配置值的既有校验行为。
5. 回归零历史、引用去重、附件失败、预览无写入、远端来源不可用、预算裁剪与回复闭环；通过前不切换正式运行入口。

## 本批 O1–O3 行为说明

无来源 create/send 现在保留消息源、消息内容、未知字段、投递时间和可选投递 ID。响应 `data.warnings` 为字符串数组：完整来源为空；未提供来源和来源不完整分别给出提示。正常化必填校验与 wire 字段不变。精简包当前情况新增消息 ID、引用 ID 与去重后的消息组 ID。未发布，实际安装版仍需后续授权切换后验收。
