# 手机位置记录

[English](mobile-location-recording_en.md) | 简体中文

手机 **记录** 页统一显示录音、录像和位置；在“全部类型”中选“位置”可单独查看，点击位置记录显示时间、地点、经纬度及精度。顶部显示位置采集和当前采样间隔。配置与导出可点击顶部位置状态，或打开 **设置 → 位置记录 / 记录 → 设备 → 手机 → 位置记录**。此功能属于实验应用；构建、设备验证和全天持续运行分别验收。

## 使用

1. 打开系统定位，授予定位权限。精确位置提供更清晰的轨迹；近似位置保留其实际精度。
2. 点击“开始仅位置记录”，或打开“全天记录时同时保存位置”并保存，再从记录页开始音频记录。切换仅位置会提示暂停当前音频或视频。
3. 通过全天记录总开关暂停。关闭高德地点查询只停止高德请求；关闭总记录停止全部采集。暂停后可“切回音频记录模式”。
4. 在统一记录页按日期回看、按手机来源或位置类型筛选，上下翻页可读取更早位置。位置设置页显示当天最近 200 个点，“导出当天轨迹 GeoJSON”包含当天全部点。

默认常规定位间隔 60 秒、快速移动最短间隔 5 秒、记录位移阈值 10 米，均可在位置设置中修改并立即应用。运动检测先把目标间隔缩短到 15 秒；可信 GPS 速度达到 2 米/秒，或扣除误差后的连续坐标变化确认快速移动时，缩短到最快间隔。最快间隔不会大于常规间隔。

使用低功耗显著运动传感器，设备不支持时使用低频加速度计；没有可用传感器则由定位结果调频。陀螺仪的转速不能代表行进速度。运动提示保留 90 秒，快速移动证据保留 60 秒，持续移动会续期。精度在 50 米以内的新鲜位置确认静止三分钟后，目标间隔放慢至至少两分钟；静止十分钟后至至少五分钟。定位中断或精度不足时回到常规间隔，匀速行驶可凭 GPS 速度保持快速采样。传感器只缩短下一次定位的等待时间，无法单独确认移动了多少米。

获取定位、保存轨迹、查询高德地点名称分别控制。新点距离需超过用户阈值和前后两点组合误差中的较大值，最短保存间隔采用最快定位间隔；静止时约每五分钟保存一个新鲜样本。10 米是记录阈值，定位误差较大时不会承诺 10 米级轨迹。页面显示当前目标间隔、运动检测方式和相邻已保存位置的直线距离。实际定位频率与耗电取决于系统、信号和省电策略，设置间隔并不保证 GPS 芯片按该间隔开关。

WGS84 坐标、时间、精度和定位来源存于手机私有 SQLite，断网可保存。系统提供的可选速度及速度精度用于调频，不写入轨迹；未提供速度时使用扣除误差的坐标位移辅助判断。当前没有自动上传到 PC/Relay 或电脑 Agent 轨迹查询。

统一时间线直接读取同一 SQLite 数据，旧版保存的位置也会显示，不复制第二份记录文件。位置是一个采样时刻，时间尺只标记该点，不把两点之间画成持续定位覆盖；点击位置不会启动音频播放器。电脑归档目前仅提供录音，查看位置需选择“本机记录”。

仅位置模式无需麦克风。锁屏由现有全天记录前台服务维持定位，仍受厂商省电限制。进程被终止或手机重启后，请打开应用恢复；不承诺系统强制停止后自动启动定位。

## Android Key 与配额

使用高德 **Android 平台** Key，绑定 `com.rabi.link` 包名及安装包签名 SHA-1；Web 服务 Key 不适用。在手机输入后由 Android Keystore 加密保存，不写入源码、APK、日志、导出或 PC/Relay 配置。输入留空保留已有值，清除按钮删除本机 Key 并关闭高德查询。

开启 SDK 前阅读应用内说明与[高德隐私政策](https://lbs.amap.com/pages/privacy/)，同意其处理位置、设备、网络和 Wi-Fi/基站等信息后才初始化。系统 GPS 无需高德 Key。

高德单次联网定位只为原始位置补充地点名称，返回位置须经坐标系转换后与原始位置足够接近，否则不附加名称。附近 150 米复用缓存；新请求至少间隔十分钟，失败等待后续样本再试。精度差于 150 米的系统样本不查询地点。

截至 2026-10-26，[官方公开配额](https://lbs.amap.com/pages/base_service_price)对个人认证开发者列出：基础地图定位 **150 万次/月**（含 Android 在线定位），基础 LBS 服务 **15 万次/月**。各类为共享额度，实际账号权益与计量以控制台为准。

本机默认上限 **10,000 次 SDK 定位/月**，失败和手动测试也计入，按北京时间自然月更新。每十分钟一次、连续 31 天约 4,464 次，缓存会减少调用。本机统计 SDK 发起次数，不等同 SDK 内部网络次数或账号账单；不约束同账号其他设备。达到上限只停止高德请求，系统 GPS 继续，轨迹保留。

## 实现与验证

`RabiConversationService` 是唯一采集 owner，`LocationController` 管理系统监听与迟到回调，`LocationRepository` 保存原始点、地点缓存、事务化月计数及流式 GeoJSON 导出。`AmapLocationLookup` 使用 Android 定位 SDK 6.5.1 单次定位、HTTPS 和超时，不调用 Web 服务。选择该纯定位版本以符合精简包体积约束。

执行 Android 单元测试与 `LocationInstrumentation` 隔离数据库、加密、并发配额测试。真实 SDK 需有效 Android Key、包名签名匹配、联网、权限及隐私同意。另验收仅位置启动、暂停、后台新样本、断网保存、恢复与导出。模拟样本不能证明真实 GPS 或全天电量表现。

2026-10-26：`0.3.68-dev`（71）已通过 294 项 Android 单元测试、根目录 `npm run build`、精简包与签名校验，并覆盖安装到 Android 真机。隔离存储测试通过加密回读、数据库重开、GeoJSON 坐标顺序、缓存及并发月上限；真机收到真实位置和高德地点名称。仅位置启动的服务类型为 location/dataSync，暂停后移除 location。全天锁屏、长距离移动、厂商省电及电量消耗尚需持续实测。

自适应版本 `0.3.69-dev`（72）通过 304 项单元测试、完整构建及精简包校验，已安装到真机。设备验证了采样设置持久化、低功耗显著运动监听注册、默认 60 秒状态和新位置保存；音频与位置记录已恢复。5/15 秒移动档、2/5 分钟静止档、漂移过滤、过期运动信号、匀速行驶及无速度结果已通过确定性单元测试；真机行走切档、锁屏长时间耗电和传感器降级仍需实测。

统一时间线版本 `0.3.70-dev`（73）通过 304 项单元测试、完整构建和精简包校验。真机隔离测试覆盖旧点投影、超过 200 个点的双向翻页、跨类型同时间游标及地点更新通知；实际页面已显示旧位置卡片，“位置”筛选和详情打开通过验证。
