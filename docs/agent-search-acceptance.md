## 代码与运行结果复核

沿实际调用链修复并回归以下问题。

- 冷加载遇坏知识文件时保留健康记录，局部全量重载保留原有效条目，旧查询响应增加部分覆盖说明。

- 保留现有目录 operation ID、参数、summary 字段和完整合同，修复 OpenAPI 响应 schema 的必填属性错误。
- 确认状态与用户确认需要原拥有者依据，检索时间独立于观测时间。原拥有者的冲突报告和空冲突报告均有明确表达。
