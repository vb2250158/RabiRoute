连续时间尺使用固定游标显示当前时刻，可横向惯性滚动跨日回看、双指缩放或双击放大；到达最新时刻进入实时，也可点击“回到实时”。绿色表示已保存录音，青色表示录像，空白表示缺口。下方事件随可见时间范围刷新；点击事件把游标与播放器定位到该记录，播放进度同步时间尺。历史录音按时间窗口加载，不再受最近 500 条限制。

预览区固定为同一高度，实时、加载、空缺、音频和视频回看切换时，日期栏、时间尺及事件列表保持原位。回看控制置于预览底部，时长置于顶部；分享收进“⋯”记录操作菜单，不再追加整行按钮。

音频和视频共用播放器浮层与唯一混合时间轴。进入或切换记录时控件默认隐藏，点击一次预览显示，再点一次隐藏；播放时 3.5 秒后自动收起，启用触摸探索时不自动隐藏。播放进度同步下方时间尺，不增加单独片段进度条。控件覆盖在内容上方，显隐不改变预览高度。

## 自动选源与统一回看（0.3.26-dev）

音频模式不再提供手动来源选择。明确开始后先使用手机；已授权眼镜提供 CXR-L 音频时切换到眼镜，断连或 5 秒未收到数据时回到手机。切换先封口旧记录，再创建具有真实物理来源的新记录；暂停后不因设备重连重新采集。眼镜连接通道仍需首次授权。

时间线页上方固定预览、日期和可拖拽时间轴，最右端为实时，向左回看历史。纯音频时显示与 WebGUI ASR 收录一致的柱状声波；实时声波读取同一采集链路的 PCM 音量，历史声波读取保存的 WAV，标出播放位置。没有声音或画面时显示“无画面”。下方按时间显示录像缩略图、录音及关联 ASR 文字；点击卡片定位上方播放器。纯录音、带声音录像共用播放器，原始视频分段可跨段定位。手机音频按已保存分片的时间与实际字节时长映射；无记录时显示空缺。

实时页随采集状态更新；仅在可见实时页每 30 秒刷新一次已验证电脑的转写，仍限最近 24 小时、最多 200 条。退出页面停止刷新。ASR 保留供应商说话人信息；当前合同没有整条录音内的句子偏移，点击文字定位所属记录，不伪造逐字对齐。视频派生音轨按父 captureId 关联，避免重复显示同一录像的派生录音。历史视频的系统时钟映射沿用会话时间，尚无逐帧墙钟同步证明。

分片 MP4 时长从实际帧时间读取，回放生成可拖动的本地缓存，保留原文件。待传音频字节统计由队列维护，避免每次写入重读全部历史分片。

源码回归、安装及本轮真机结果见下方验收记录；实时视图不自动开启新的采集。

## 统一日常入口

底部只有“记录、消息”两个标签。“记录”默认显示时间线，顶部“开始记录”开关控制采集；右上角进入第二页“记录设备”，用双列卡片展示手机、眼镜、手表／手环及电脑。返回记录或系统返回键回到时间线。设备卡片只提供必要连接与授权，没有常规模式、来源或处理设置表单。

本次导航变更保留已保存的采集和处理策略，不重写历史记录，也不因打开设备页开始采集。音频来源仍由唯一采集服务自动选择。旧 home 启动参数统一进入时间线，独立首页、设备标签和重复预览入口已移除。已保存记录仍按原策略处理；眼镜视频和健康能力的验收范围见下文。

## 保存、转写与回看

- `RabiConversationService` 是唯一运行 owner；旧独立本地音频、录像及设备状态 service 已从本轮源码移除。视频由普通 controller 接收，音频统一写 durable spool，健康 controller 服从总许可和允许窗口。
- 新记录冻结 `captureId`、物理来源、Route 与处理策略；切聊天人格不改投排队记录。本地媒体和转写按记录关联，不把当前会话当成历史归属。
- 新转写已按 `captureId` 只读关联；刷新最近 24 小时、最多 200 条、按 `processedAt` 查询的结果；可见实时页有界刷新，历史页手动刷新。缺 ID 不猜归属，不能称完整历史回看。健康目前只统一采集/状态，完整历史仍在 PC。
- `autoResume` 无行为 UI 已移除，仅内部保留 false；开机明确暂停，自动恢复采集尚未实现。
- `local_only` 不提交处理；`transcribe` 要求 PC 支持仅转写且不投递 Agent；能力与 worker 围栏已接入源码，最终验收仍待，无支持时保留 `deferred`，不得降级为 Agent 投递。排队、上传确认、转写完成分别显示。
- 一次视频对应一条记录，内部原始分段按顺序回放。分享导出原始分段，不伪称合并文件。旧 WAV、视频、PCM 队列及已收到转写保留，不改写来源。
- 新记录即使收到传输 ACK，也**不会按旧传输缓存保留期限自动删除**。当前尚未实现完整自动滚动删除，不能称全天容量管理已经完成。未确认/隔离数据不静默删除；空间不足停止接收并报告。

## 状态、隐私与设备边界

开始接收不等于眼镜开播，收到视频才计为真实覆盖。授权、连接、实际数据和 PC 处理分别显示。模式切换、设备断线或写入异常的缺口必须可见，服务存活时长不是录音覆盖。

手机暂停不等于已关闭厂商眼镜相机或手表测量。手动乐奇直播仍需在乐奇结束；PC 健康 Companion 未确认停止时要显示远端未确认。允许窗口及历史隐私区间必须阻止恢复后的迟到健康样本补入。

原生乐奇手动直播保留已有真机证据；自有眼镜自动安装/开播仍需单独验收，不使用 CXR-M。旧录像入口如有兼容调用，只能转到统一 owner，不能恢复旧独立 service。

### 录音事件拆分

0.3.33 开始，新采集音频按独立事件保存边界：有效声音累计至少 1 秒后，低于声音阈值持续 500 毫秒结束事件；最长 60 秒（包括纯静音）。这些默认值参考 PC ASR，手机按 PCM 能量判断停顿，不表示已识别人声。所有 PCM 均保留，不删除静音，不重复预录音。5 秒可靠存储分片与事件是不同层，事件可跨多个分片。

记录右上角的设备页提供“记录设置”：停顿滑条 200–3000 毫秒（步长 50 毫秒）、最长时长滑条 3–120 秒（步长 1 秒），可恢复默认；保存后下一事件生效。事件 ID 写入分片及恢复元数据，重启不重新拆分已有事件；旧记录缺少事件 ID 时沿用原记录。每个新事件可独立回放和分享，点击仍定位时间轴。录音总开关、来源和本地/上传策略保持独立。PC 目前仅返回整次采集关联，缺少可靠事件时间偏移时仅在首个事件标注整次转写，不复制到每个片段。事件拆分本身不启用上传或 ASR。
