# 连接与接口使用

电脑凭据中的单条坏记录按节点隔离，其他独立验证通过的连接继续使用。重复 `nodeId` 的所有记录均隔离，不猜选其中一个；原数据保留，新增登记不能覆盖其身份。`GET /api/lan-agent/instances` 和 `/api/lan-agent/nodes` 的 `credentialDiagnostics` 返回记录位置、可识别节点 ID 和原因，不返回凭据或哈希。修复时先备份本机私有 `data/.runtime/lan-agent-authority.json`，由原管理流程确认正确身份后修复对应记录；不要删除整份凭据或让所有电脑重新接入。整个 JSON 或版本结构无法解析时仍报告文件故障。

远端连接器 0.2.6：电脑凭据认证整台实例，“是否启用Agent”控制整个实例，默认启用。启用后可直接使用主机全部公开接口，包括改名、计划、记忆、Skill、文件与任务；不要求浏览器登录、主控 Agent、会话登记、绑定或逐功能授权。每次 Agent 调用明确传入实际类型与完整会话 Id；目录和会话列表用于查询，不授予权限。

状态：0.3.25 实现。完成一次连接鉴权后，使用这条连接提供的接口即可，不再为每个功能、角色或技能重复授权。接口目录用于发现能力和参数，不是另一份权限白名单。

本机操作使用当前 Host 发布的 Manager 地址；局域网 WebGUI 使用已配置的连接密钥，远端 Agent 使用接入时取得的电脑凭据及本次实际类型、完整 Id，同一 RabiLink 应用中的设备复用应用认证。后续请求继续携带已有凭据，不需要再次配对或申请功能权限。撤销连接、停用实例 和关闭服务仍会生效。

## 默认全功能，只有明确配置才禁止

连接建立并鉴权成功后，RabiLink 与远端 Agent 默认可使用 RabiPC 全部公开接口。没有逐接口或逐功能的第二次许可；未设置权限项时按可用处理，不把缺省当作拒绝。只有用户在 WebGUI 或配置文件明确禁止的能力才被限制，且只影响该配置声明的范围。已有远端 Agent 接入开关控制是否接入，不隐含接入后功能默认关闭。

计划、角色、工作区、Route、Skill 与接口目录不授予或收回接口权限。拉取合并、提交检查和风险审查不能自行创建禁用项、要求额外密钥、删除连接租约或关闭配对。请求格式与版本校验负责避免错误和重复执行，不是另一层用户授权。

## 已移除的重复限制

| 入口 | 当前行为 |
| --- | --- |
| 米家控制 | Home Assistant 连接成功后可直接执行设备支持的动作，无“允许控制设备”开关。 |
| 米家录像读取 | 复用 Manager 连接鉴权，无独立录像读取 token。录像采集仍由用户选择是否开启。 |
| 角色脚本 | 已配置的本机自动化可以运行所属角色 `scripts/` 中的脚本，无额外 Route 执行权限开关。远端角色脚本在其所属电脑执行。 |
| 发送消息 | 主角色、计划 Agent、秘书及消息处理 Agent 使用同一发送合同，无“仅允许主角色发送”开关。 |
| 角色技能 | 已鉴权 Agent 可以读取和下载角色技能，无逐角色 Route 绑定要求。读取不自动执行脚本。 |
| Agent API | 已鉴权节点使用 Manager 提供的接口，目录外的已有接口不会要求第二个 WebGUI 管理密钥。未知接口仍返回未找到。 |
| RabiLink | 同一应用的已认证设备沿用已有默认服务访问，不新增逐服务许可。 |
| 节点、Peer 与 WebGUI 设置 | 已鉴权连接可管理节点、查询或调用 Peer、修改局域网访问设置，无需第二个管理密钥。 |
| 游戏集成、模型目录及录像归档设置 | 复用连接鉴权，已认证的远端连接不再被本机地址限制拒绝。模型路径、归档归属、版本及幂等条件继续校验。 |
| 浏览器历史桥接 | Manager 业务接口复用连接鉴权；浏览器扩展仍以配对时取得的凭据标识自身连接。 |
| 已安装插件 | 直接使用 Manifest 声明的宿主接口，不再要求 Profile 再次列出 `grants`；未声明的宿主接口仍不属于插件合同。 |

已鉴权连接发送或委托任务时，每次显式提供 Agent 类型和完整会话 ID；无需把当前聊天加入预登记会话列表，也不改写连接器保存的会话。上传记录是主机公共资源，已鉴权主机或其他连接可按原 uploadId 查询，并用 fileId + SHA-256 引用原文件；上传者身份仅作审计，不能充当第二层功能许可。连接撤销、明确停用、文件有效期及内容完整性继续生效。

## 请求仍需正确

消息必须遵守[投递合同](rabi-agent-interfaces.md#消息投递rabi-可用时统一走-rabi)：明确发送者、目标、回复要求及关联标识；不能冒充其他会话或系统消息。设备动作使用其实际能力和参数。状态版本、配置 revision、Manager 当前身份和稳定幂等键用于避免写错对象及重复执行；它们不要求用户再授权一次。超时或结果不确定先读取原回执，不换键重复投递。

本地文件发送默认不限制目录。用户在 Route 的 `messageAdapterPolicies.<channel>.allowedFileRoots` 配置非空列表后，才限制为其中的真实目录；未配置或空列表表示不限制。拒绝提示包含配置入口、当前列表和作用范围。文件存在性、普通文件类型和内容 hash 仍按实际发送合同核对。计划附件及上传记录继续按各自 ID 定位文件。下载大小、处理期限和并发限制是服务运行合同。插件按自身 Manifest 使用宿主接口，不再经过另一份 Profile 权限许可；进程隔离与包来源校验继续执行。Windows 管理员权限、平台账号权限和设备本身不支持的能力，由对应系统决定。

安装程序、Host 生命周期和仅在本机有意义的进程操作仍在本机执行。允许远端使用业务接口不会把远端请求伪装成本机请求。摄像头采集、事件监听、路由启停和用户自行配置的审批流程是功能选择，不因本次修改自动开启或删除。

QQ 原消息、历史分页与附件读取复用当前连接鉴权。已启用并鉴权的 LAN Agent、Relay 和 P2P 来源可调用这些接口；角色、工作区和 Route 绑定不另作接口许可。代理来源须由当前连接证明，裸请求头不能冒充已鉴权来源，连接撤销后在途响应也须停止。

`/api/internal/` 角色投影接口用于 Manager 与其子进程之间核对当前路由和角色身份；普通 Agent 通过公开的角色接口读取内容，无需申请投影接口凭据。实例 ID 重置及 Host 生命周期由当前安装版宿主处理，不能把别的电脑的请求当成本机宿主命令。

QQ 附件与收藏表情使用所选 NapCat 返回的 HTTP(S) 资源地址，支持 CDN 域名、显式端口及资源重定向，不内置域名白名单。用户配置的 HTTP(S) NapCat 可以位于局域网或远端；消息、群文件、诊断读取不另加回环地址限制。已鉴权的 Relay/P2P 连接复用原连接身份和有效期。


QQ 读取配额由 Manager 进程环境变量配置，修改后通过正常 Host 生命周期加载；接口目录中的字节上限取当前生效值。未设置或设为 0 的媒体大小不施加应用层配额，仍受 Node Buffer 与实际内存能力限制。配置值非法会明确报告变量名，不静默改回默认值。

| 环境变量 | 默认值与含义 |
| --- | --- |
| `RABIROUTE_QQ_JSON_MAX_BYTES` | `0`：QQ 上游 JSON 回复无应用层字节配额 |
| `RABIROUTE_QQ_MEDIA_MAX_BYTES` | `0`：附件无应用层字节配额 |
| `RABIROUTE_QQ_STICKER_PREVIEW_MAX_BYTES` | `0`：表情预览无应用层字节配额 |
| `RABIROUTE_QQ_READ_TIMEOUT_MS` | `8000`：消息查询截止毫秒 |
| `RABIROUTE_QQ_MEDIA_TIMEOUT_MS` | `30000`：附件读取截止毫秒 |
| `RABIROUTE_QQ_STICKER_PREVIEW_TIMEOUT_MS` | `10000`：表情预览截止毫秒 |
| `RABIROUTE_QQ_READ_CONCURRENCY` | `2`：同时读取数量；繁忙提示包含此配置入口 |
| `RABIROUTE_QQ_STICKER_COUNT` | `1000`：向 NapCat 请求的默认/最大收藏数量；上游实际返回的有效条目不再被本地截断 |

媒体字节值支持非负安全整数；超时支持 1–2147483647 毫秒，数量及并发支持正安全整数。上游收藏接口没有游标，因此保留 `completenessUnknown` / `potentiallyTruncated`，不能把一次结果说成完整收藏。主动取消仍结束本次请求，读取超时与用户配置拒绝分别报告。


QQ、Markdown 和发送分段额度按使用该字段的功能读取。非法值返回 `READ_SETTING_INVALID` 并指出变量名，不阻止 Manager 启动，也不阻断普通文本发送等无依赖功能；不会把错误配置自动解释为不限额。修正进程环境后，通过正常 Host 生命周期重新加载。

## 旧配置迁移

为读取既有安装配置，0.3.25 仍接受 `writeEnabled`、`artifactReadTokenEnv`、`personaAutomationScriptsEnabled` 和 `codexHooks.onlyPrimaryPersonaCanSendMessages`。这些字段已不参与权限判断；设备控制和本机脚本可用，主角色专属发送限制停用，录像内容复用连接鉴权。界面及新示例不再提供它们。兼容输入只在配置读取边界保留，计划于 0.4.0 删除；升级时应从旧配置移除字段，使用正常连接、自动化配置或 `dryRun` 预演。

旧版本日志保留发布当时的行为作为历史记录；当前操作以本页和运行接口为准。

### Markdown 渲染与上传存储额度

以下为 Manager 启动环境变量；设置后通过正常 Host 生命周期重启生效。无效数值会指出变量名，不会静默使用默认值。Markdown 配额均接受非负安全整数，0 表示不设应用额度；运行时内存、Chromium 的实际渲染能力和正整数视口范围仍适用。超限错误包含变量名、当前值、实际值和调整方式。

| 变量 | 默认值 | 含义 |
| --- | --- | --- |
| `RABIROUTE_MARKDOWN_MAX_SOURCE_BYTES` | 0 | 单段 UTF-8 源文额度 |
| `RABIROUTE_MARKDOWN_MAX_HEIGHT` | 0 | 单张渲染图片高度，像素 |
| `RABIROUTE_MARKDOWN_MAX_PNG_BYTES` | 0 | 单张 PNG 字节额度 |
| `RABIROUTE_MARKDOWN_MAX_MESSAGE_PNG_BYTES` | 0 | 单条消息中 Markdown PNG 的总字节额度 |
| `RABIROUTE_MARKDOWN_TIMEOUT_MS` | 15000 | 浏览器启动、连接和各 CDP 操作超时；1–2147483647 毫秒 |
| `RABIROUTE_AGENT_UPLOAD_MAX_TOTAL_BYTES` | max(16 GiB, 单文件额度) | 上传存储及进行中预留的总字节额度 |
| `RABIROUTE_AGENT_UPLOAD_MAX_FILES` | 100 | 上传存储及进行中预留的文件数量 |
| `RABIROUTE_AGENT_UPLOAD_TTL_MS` | 86400000 | 新上传文件保留时间，毫秒 |

上传存储三个变量为正安全整数；已有文件保持原过期时间。单文件额度在 WebGUI「RabiLink → 配置」或 `data/Config.json` 的 `agentUploads.maxFileMiB` 设置，默认 2048 MiB，接受 1–8589934591 的整数（上界来自精确字节计数能力），不再额外截到 2 GiB。保存后重启 Manager 生效。降低新上传额度不会把已接收文件判成损坏。目标平台是否接受该大小由其实际接口结果决定。

QQ 表情预览保留上游合法的 `image/*` MIME，包括 AVIF、BMP、SVG；非图片响应或无效 MIME 会明确失败。客户端是否能显示该格式取决于其图片呈现能力，不通过固定扩展名集合隐藏图片。
