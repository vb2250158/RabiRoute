# 内嵌计划视图

单计划页 `/routes/:id/plan/:planId` 在 iframe 中打开时，直接显示计划内容，不显示全局导航、顶部语言与连接状态、全局保存按钮，以及专注和刷新工具栏。DSH 的绑定计划面板自动使用这个视图，无需额外参数；多个绑定计划仍由 DSH 目录选择。

计划详情、附件、步骤、反馈和事件更新继续使用同一页面。加载失败时保留错误说明和重试入口。独立打开该地址仍显示完整 Rabi Web 导航与工具栏。

重复打开同一计划时，页面先从浏览器会话存档显示最近一次完整详情，再向 Manager 发送视图版本；未变更时返回 `304`，不重复传输详情与附件元数据。计划、审批或人格状态配置变更后，Manager 返回新详情并更新存档。存档最多保留 8 条计划、400 万个 JSON 字符；浏览器存储额度不足时跳过存档，不影响当前详情。读取失败会显示错误，不把旧内容当成已校验的新结果。计划事件只刷新当前目标计划，其他计划事件不触发该页详情读取。

所有计划页的关联 Agent 区域共用紧凑布局：只保留外层边框，每个 Agent 用两行显示会话标题、Agent 类型与工作区，右侧显示一个状态标签。长标题与路径省略显示，悬停可查看全文；重试状态及可用的会话打开操作保留。

DSH 面板在路由查询参数中传入 `embedAgent=dsh` 和 `embedSession=<当前会话 ID>`。内嵌页据此隐藏计划引导，并从关联 Agent 列表中排除同处理端、同会话 ID 的绑定；其他绑定继续显示，列表为空时隐藏整个关联区域并跳过该区域的状态查询。独立页面忽略这些展示参数，保留计划引导和所有实际绑定。这些参数不授予任何业务权限。
