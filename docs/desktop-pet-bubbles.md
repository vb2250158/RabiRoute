# 桌宠气泡与语音

单击松手后立即播放回应动作，再次单击会从头重播。双击仍打开人格面板，第二次松手不再重复回应。按住后移动超过系统拖拽阈值才开始拖动；轻微手抖保持单击，只有实际拖动才保存位置。回应结束后恢复正在播放的语音或陪伴动作；随机待机和睡眠被菜单、按住或互动暂时挡住后会继续调度。

右键菜单的“大小”显示当前百分比，展开后直接拖动滑条，在 10%–200% 之间以 1% 精度调整。拖动时复用已加载画面即时缩放预览，动画继续播放；松手或收起大小子菜单不会重建动画。关闭整个右键菜单后，才按最终大小重建一次并自动保存；调回原大小则无需重建或保存。重新打开菜单或重启会恢复已保存的大小。

桌宠右键勾选“显示气泡”。陪伴评论、任务结果和本机人格语音共用普通对话气泡。进入 RabiSpeech 主机播放队列且 `voice` 等于桌宠人格 ID 的语音开始播放时，气泡显示对应文字，桌宠播放说话动作；播放结束后默认保留 8 秒。普通提示不会覆盖正在说话的文字。

气泡只显示文字。长文字可滚动，最多显示 4000 字；窗口不抢焦点。点透开启时气泡也点透。隐藏桌宠或关闭气泡只影响显示，声音仍由语音队列控制。

右键“气泡样式…”可预览并保存猫爪或纯色外观、系统字体、字号（12–24 px）、文字颜色、宽度（220–480 px）、不透明度（50–100%）和停留时间（2–30 秒）；纯色外观还可修改背景和描边。人格面板的桌宠设置提供相同配置。每个人格单独保存，重启后恢复。猫爪框体通过九宫格绘制，右下角纹理保持固定大小；尖角独立绘制并对准桌宠可见轮廓的横向中心。框体靠近屏幕边缘时自动限位，尖角继续跟随；上方空间不足时气泡移到桌宠下方，尖角朝上。正文与纹理之间留有空白。

桌面订阅 Manager 的 `/api/speech/events` 并读取 `/api/speech/playback/status` 恢复正在播放的一句；重连不弹出旧历史，也不自动重播。Qt 只展示，合成、播放、音频缓存和队列状态仍由 RabiSpeech 拥有。

设置保存在 Manager 的人格桌宠绑定 `bubbleStyle` 中，通过原有 `/api/desktop-pet/roles/{personaId}` 更新，桌面不直接写配置。底图位于桌面运行包的 `rabiroute_tray/assets/bubble-cat-paw-body-v2.png`；九宫格切分比例与固定绘制尺寸见同目录资源说明。浏览器自行播放的音频、远端设备播放和未匹配人格的系统音色不附着到本机桌宠。
