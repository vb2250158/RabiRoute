## 后续发现：冻结包不可推荐生产部署

真实 Chrome 验证手机知识授权页时，原生 `fetch` 经 `env.fetch` 调用因 `this` 接收者不合法抛出 `TypeError: Illegal invocation`，请求未到 HTTP 层。此前最小 DOM/HTTP 测试未发现此浏览器集成缺陷。共享源码的 native fetch wrapper 已修，授权输入在 initial/busy/pending 状态禁用，label 触控高度 44px、checkbox 20px；相关测试 7/7 通过，退出码 0。真实 Chrome 在 320/390/768 宽度分别完成 profile 与 grant 保存，GET 回读对应 revision 1/2/3 一致；共六页无横向溢出，长工具 label 中心点击命中。父任务独立目检 grant 320 截图。以上是桌面真实 Chrome 的手机尺寸验证，不是手机真机验收。

冻结产物 `release0.3.15-e6e3709e82f8` **包含该缺陷，不可推荐生产部署**；尚未安装，因此未将缺陷部署到现有运行环境。上表大小、哈希与构建验证仍是该旧包事实，不是当前生产可用证明。后续 fetch 修复和新增原键回执恢复均不包含在该冻结包中，必须在验证后重新打包。
