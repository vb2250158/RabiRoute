## 0.3.49 激活超时备忘

Developer 激活与发布脚本默认只等 120 秒；Host 自身允许 Manager 启动 180 秒、托盘启动 120 秒，另有健康准入与启动引导时间。外层预算短于内层预算，会把仍在正常启动的候选提前回滚。

本机日志显示，回滚指令抵达时候选 Manager 仅启动约 66 秒；随后替换进程遭遇旧 Manager 的单实例保护。下一版将两个脚本的默认预算统一为 420 秒，并把修复后的脚本纳入不可变候选包。代际围栏、指针比较交换、完整就绪核验与失败回滚继续生效。

420 秒是有界等待预算，不保证所有慢存储启动都成功。启动取消后的子进程退出时序、Manager 心跳失败重启、计划存储降级仍须分别跟踪；本次预算修复不作为这些问题已解决的证据。其他机器曾报告相似慢启动症状，尚未核对其现场日志，不据此认定同一根因。

后续正式部署应回填：最终提交、完整 releaseId、安装机器、Host/Manager 代际核对、活动包、拖拽/抛掷/滞空循环/缩放及双屏往返的证据位置。
