## 0.3.49 激活超时备忘

Developer 激活与发布脚本默认只等 120 秒；Host 自身允许 Manager 启动 180 秒、托盘启动 120 秒，另有健康准入与启动引导时间。外层预算短于内层预算，会把仍在正常启动的候选提前回滚。

本机日志显示，回滚指令抵达时候选 Manager 仅启动约 66 秒；随后替换进程遭遇旧 Manager 的单实例保护。0.3.50 已将两个脚本的默认预算统一为 420 秒，并把修复后的脚本纳入不可变候选包。代际围栏、指针比较交换、完整就绪核验与失败回滚继续生效。

420 秒是有界等待预算，不保证所有慢存储启动都成功。启动取消后的子进程退出时序、Manager 心跳失败重启、计划存储降级仍须分别跟踪；本次预算修复不作为这些问题已解决的证据。其他机器曾报告相似慢启动症状，尚未核对其现场日志，不据此认定同一根因。

本次正式安装为 `0.3.50-00c1b4327a20`，构建源码为 `562b4a4c`，活动包为 `yeyu-library-flat-wide-airborne-v20`。私有部署回执记录机器身份、完整代际核对、两屏生产窗口截图、安装版拖拽/抛掷/滞空循环/缩放证据；截图和运行数据不进入公开仓库。Host 整体健康仍为 `degraded`，不把桌宠验收扩写成所有后台功能健康。

## 同批源码合并

补充的生产窗口缩放验收发现：0.3.50 在 75% 缩回 50% 后会保留放大时的窗口高度位置，造成 128px 空隙。0.3.52 已在缩放变化后重新应用保存的位置，并补充“缩小恢复贴底”和“其他设置不打断当前位置”回归；安装复验另行记录。

0.3.52 复验已确认高度恢复，同时定位到首次载入用占位框计算位置造成的 10px 横向偏差。0.3.53 在首帧真实尺寸就绪后重新定位，并保留素材迟到前已完成的用户拖动；最终安装复验另行记录。
