# 查看消息记录

在侧栏打开“消息记录”，选择角色和消息渠道。各标签采用左侧列表、中间正文和右侧关联信息的布局。

- **Agent 间投递**：左侧每个任务一项，包含只收到消息的任务。选择后按写入顺序查看该任务全部发送与接收记录，右侧列出有过收发记录的任务。点击右侧任务可切换视角。每条消息保留实际发送方、接收方与已有回执；待确认送达仍显示待确认。
- **角色面板**：按目标任务阅读用户提交的消息，右侧查看原任务资料。
- **任务回复**：按来源任务阅读最终回复，保留原任务入口。
- **NapCat / OneBot**：保留群聊、私聊、群成员、引用消息和媒体预览。
- **系统消息、定时触发、语音及插件渠道**：按原账本中的会话身份阅读；右侧查看渠道与来源。旧记录缺少规则或设备名称时保留已有来源，不推测归属。

任务名称相同但 ID 或宿主不同的记录分别展示。列表由历史索引生成，不依赖当前屏幕加载的消息数量；“更多会话”“更多任务”和“加载更早的消息”继续读取原历史。任务列表按索引中的最近写入顺序排列。

搜索任务使用索引中的名称快照。普通消息端的搜索作用于已载入的会话列表，更多会话可继续加载。消息正文保留 Markdown、代码、长文展开与已有附件信息。切换标签保留选中对象，任务正文缓存最近 12 个视图；更早内容始终可重新加载。

窄窗口把右侧信息收进详情弹窗。手机先显示列表，点击后打开正文，返回按钮回到列表。会话列表宽度可拖动调整，也可聚焦分隔条后使用左右方向键。

读取失败时保留已有内容，在受影响区域显示重试。部分损坏记录保留诊断，其他记录继续可读。查看历史不会重新投递消息。

接口与分页合同见 [Rabi Agent 接口](rabi-agent-interfaces.md)。本页描述源码候选行为；安装环境生效以实际部署版本为准。
