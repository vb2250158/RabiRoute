# Agent 会话任务术语规范

本规范统一 RabiRoute Agent 端的文档与界面用语。规范术语已确定；附录的批量文案改写等待确认，本次不重命名实现或迁移已保存配置。

## 三层术语

| 层次 | 规范术语 | 领域代码名 | 定义与边界 |
| --- | --- | --- | --- |
| 容器 | 会话任务 | `AgentSession` / `sessionId` | 由 Agent 宿主拥有、可作为投递目标的容器；不是计划中的业务任务或一次执行轮次。 |
| 内容 | 会话消息 | `sessionMessage` / `messageId` | 会话任务内的一条内容；不等于整个容器，也不等于投递回执。 |
| 状态 | 会话任务状态、消息状态 | 由各自领域对象承载 | 容器状态与单条消息状态分别描述，不合并；会话任务活跃不证明某条消息已收到或完成。 |

新代码的领域类型使用上述命名；既有类型、函数和持久化字段本次保持原样。消息状态、投递状态、执行结果也应依据各自证据描述，不从会话任务状态推断。

## 宿主原生叫法映射

| 宿主 | 原生技术叫法 | 原生 UI / 存储说明 | RabiRoute 统一显示 |
| --- | --- | --- | --- |
| Codex | `thread` | UI 叫“任务” | 会话任务 |
| DSH | `session` | UI 叫“会话” | 会话任务 |
| WorkBuddy | `task` | UI 叫“任务”，数据库表叫 `sessions` | 会话任务 |
| Antigravity | `conversation` | 原生技术命名，不据此推定 UI 名称 | 会话任务 |

映射描述可以保留宿主原生词，跨宿主叙述使用“会话任务”。计划任务、后台作业、终端会话、录音会话、登录会话和普通对话不属于本次容器术语替换范围。

## 停用词与替代词

| 停用叫法 | 替代叫法 | 保留边界 |
| --- | --- | --- |
| `thread` | 会话任务 / `AgentSession` | 仅在映射 Codex 原生字段时保留；另见不可变兼容标识。 |
| `conversation` | 会话任务 / `AgentSession` | 仅在 Antigravity 原生处保留。 |
| 线程桥 | 会话任务接口 | 本次只提出既有文案改写位置，不重命名实现。 |

“会话”“任务”“线程”“对话”指代跨宿主可投递容器时统一为“会话任务”；它们在非容器业务语境中不作机械替换。

## Wire 与兼容边界

以下兼容标识绝对不改，术语规范不是协议迁移授权：

- 能力值 `agentThreads`，包括各插件 `agent-adapter.json` 的 `capabilities.managedTasks`。
- 持久化字段 `threadId`、`sessionId`、`agentAdapter`、`codexThreadId`、`dshSessionId`、`workbuddySessionId` 等，以及既有计划绑定和 Route 配置。
- 文件路径 `src/agentThreads.ts`、`dist/agentThreads.js`；HTTP 路由 `/api/agent/threads`。
- 现有请求、响应、操作 ID、代码符号及其他兼容标识按原合同保留，不能通过“显示文案”改写它们。

上述历史标识即使含停用词也继续保留。允许范围是中文文档、WebGUI 显示文案和新代码领域类型命名；本次实际修改仅限 docs，不修改 src、plugins、WebGUI 或 .workbuddy/memory，也不发布、打包或提交 git。

## 读取能力与事实边界

[会话任务接口合同](./agent-thread-api-contracts.md) 中的 `list` / `read` 返回会话任务元数据，不包含会话消息。元数据包括完整 ID、标题、工作目录、更新时间、归档、活跃及状态等信息；具体字段依 adapter 返回，不保证每个宿主都有全部字段。读取元数据不等于读取聊天记录。

现有托管能力只有 `messageProcessingAgent`、`planAssistantSessions`、`memoryConsolidationAgent`、`hooks`、`agentThreads`、`deliveryReceiptRecovery` 六项，没有读取侧能力声明。不能把 `agentThreads` 解读为支持读取消息，也不在本次新增能力值。

以上采用本次用户已核实的事实，不重新调查宿主实现。仓库 package.json 为 0.6.0，本机运行实例为 0.14.2，产物位于 `%LOCALAPPDATA%/Programs/RabiRoute/versions/0.14.2-*`；运行行为以对应运行实例为准。本次没有运行验收，不以仓库源码推断安装版行为。
