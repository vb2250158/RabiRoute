# 媒体项目与自动保存

项目真源由视频插件的 `VideoProjects` 管理，位于服务端 `stateRoot/projects/<id>.json`。浏览器通过 `/api/video/projects` 列表与创建，通过 `/api/video/projects/<id>` 读取与保存；项目 ID 位于页面 URL 的 project 查询参数。它不依赖浏览器 localStorage 或 IndexedDB，远端客户端访问同一服务与项目 ID 时读取同一份内容。

创作页支持我的项目、新建、打开、编辑项目名称和返回列表。卡片、位置、提示词、首尾帧、参考资产 ID、生成参数和本地生成音频随项目保存。音频 Blob 序列化到项目文档，读取时重建播放 URL；视频等已上传素材保留服务端资产引用。临时播放 URL 不作为持久资源。

受鉴权的局域网 HTTP 入口支持新建项目、新增与复制卡片及提交生成任务。浏览器统一通过 `crypto.getRandomValues()` 生成 UUID v4 和幂等键，不依赖仅在安全上下文可用的 `crypto.randomUUID()`；服务端项目格式与访问控制不变。

编辑触发串行自动保存，保存进行中产生的新编辑合并为下一份最新快照。页面无正常保存状态提示。网络失败或并发冲突显示错误，未保存时离开触发浏览器保护提示。项目读取失败不覆盖已有文件。当前失败后不自动覆盖重试，需保留编辑并排查恢复；不承诺断网时仍已保存。

服务端采用临时文件加 rename 原子替换与 revision 比较，同一进程串行提交。不同客户端基于相同 revision 提交时，后到者收到 409，不能静默覆盖。无过期、自动清理或归档策略；本轮不删除项目。单次项目请求限制 64 MiB，超过限制拒绝写入。

模型推理、模型安装与项目存储是不同能力，项目保存不触发 GPU 工作。正式插件沿用 Manager 的访问控制；本地预览只有项目路由开放写入且检查 Origin，其余生成、安装路由继续只读。预览项目目录独立于安装版，交付安装版时必须迁移验证，不能把预览数据误称为已同步到安装版。

已验证：项目创建重放、服务重新实例化后的读取、并发版本冲突、项目内容隔离、只读拒绝、路径校验；浏览器新建、输入、服务端回读、刷新恢复和返回项目列表。当前项目卡片显示占位封面与编辑时间，未生成画布缩略图。
