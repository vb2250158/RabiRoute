# NapCat / OneBot

[English](README_en.md)

连接 QQ 群聊和私聊。本包拥有配置卡片、入口、协议、消息处理和运行生命周期。宿主只提供路由、历史、配置及 API 监听器等通用端口。

新建 WS 入口使用自动端口 `0`，原 Gateway 持有实际 socket 并发布地址；OneBot 配置及启动在原绑定操作内读取并核对该地址。HTTP 与 WebUI 继续使用明确配置的外部端点。Host `@3`、启动顺序、配置与运行态分工及验收边界见[动态 WS 入口](../../../docs/napcat-dynamic-ws.md)。

支持合并转发只读分页、嵌套节点与节点附件。所有读取沿原消息和会话授权范围进行；界面卡片由人格插件提供，不改共享消息存档格式。

图片已有所选原消息或转发节点提供的地址时，直接按原读取预算和字节配额下载，不先等待文件解析。图片没有地址时使用 `get_image`；视频、语音和文件仍使用 `get_file`。地址不接受调用方传入，下载请求不携带 OneBot 凭据。
