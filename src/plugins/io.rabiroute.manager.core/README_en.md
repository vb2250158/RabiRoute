# io.rabiroute.manager.core

Built-in Manager plugin. Instance `manager:core` provides `manager.core@1`. Its implementation accesses host resources only through `@rabiroute/plugin-sdk` and versioned capabilities declared by the manifest.

Advanced connection settings select Rabi-managed Speech or an explicit service URL. Saving unrelated connection settings preserves that mode. Managed mode uses the running Speech owner’s dynamic endpoint.
