# 自动化调度

[English](README_en.md)

执行角色“自动化”中的定时规则，不再提供消息连接器卡片、登录入口或扫描项。Gateway 根据启用规则和执行路由加载本包；明确投递到 DS Bot 的角色规则由本包的 Manager 入口接收人格插件的自动化来源，角色无需 Route 或主会话。两种入口共用定时计算，DS Bot 规则在 Gateway 收集任务前排除，避免重复执行。

人格插件拥有配置读取、变更通知与原生角色工作租约；Manager 调度入口拥有计时器和在途投递。配置变更沿原目录生命周期刷新来源，退役时取消订阅和计时器，并等待实际读取与投递结束。每次执行沿原自动化账本，使用角色、原规则 ID 和计划触发时间区分回执；本机连接或远端绑定原样交现 Agent Thread 路由。坏规则或不可达目标只报告该项，不停止其他规则。DS Bot 的队列接纳与结果未知按真实回执记录。

内部 `heartbeat` 标识沿用既有调度、投递与历史记录合同，不创建第二套执行器。旧配置通过正式角色配置升级工具保留任务 ID、启用状态与路由范围；缺省忙时策略保留原路由差异。新任务直接在自动化中配置。

每日规则的 `timeOfDays` 可保存多个本地时间，例如 `10:00`、`14:00`、`18:00`。调度器按当天剩余时间点依次执行，最后一点之后进入次日首点；错过的点沿原行为不补发。所有时间点属于同一规则和同一运行任务，原回执键继续包含实际计划触发时间。旧 `timeOfDay` 配置继续有效。非法列表只停用该条日程的运行，其他正常规则继续执行。
