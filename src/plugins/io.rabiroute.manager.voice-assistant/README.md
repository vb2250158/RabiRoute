# 桌面语音助手

入口 `/voice-assistant`，由独立 Manager/Web 插件注册。用户明确选择角色路由、ASR 和 TTS 后启动；不会代选 Agent、人设或云模型。角色路由必须运行，角色声音必须已配置。

三层边界：原生角色面板输入调用所选 Agent，沿用其全局提示词、人设、工具和任务记录；`packages/assistant-runtime` 的 `createVoiceInteraction` 管理通用语音循环；Rabi 宿主适配浏览器 PCM 采集、手动 ASR 和 RabiSpeech 播放队列。远端工具连接不在本插件实现。

麦克风在 ASR、模型处理和 TTS 期间继续采集。用户开口只停止语音输出，原生 Agent 的模型与工具任务继续。角色回复按 outbox 提交的 `replyToMessageId`、角色和路由关联，旧任务的文本继续显示；不按角色名称猜测所属请求。HTTP 接收不是任务完成，提交不确定时不会自动重试。消息断线重连读取原时间线并按消息 ID 去重。

每段 TTS 有独立播放会话。`POST /api/speech/playback/cancel-session` 保留宿主权限与生命周期检查，取消迟到的合成和该会话队列，不调用全局停止。播放完成由 RabiSpeech 的真实 `done` 事件决定。桌宠通过既有角色消息和播放事件显示文字/说话动作，不产生第二套录音或播放器。退出页面结束语音，已提交的原生任务仍继续。

验证应分开记录：源码/构建与夹具测试、插件安装、页面验收、真实麦克风/扬声器和回声测试。浏览器请求回声消除并不证明能消除宿主扬声器回声；本机实际 AEC、用户打断延迟仍需真机验收。当前采集用浏览器 PCM 处理节点，20 秒切段、最多 4 个待识别段；过载停止并显示错误。它不是全双工模型，也不声称与 GPT Realtime 延迟等同。

部署需要同时更新 Manager（回复关联、按会话取消）与 Web 插件。旧服务缺少关联字段时，页面不会把无法归属的角色消息朗读出来。构建沿用仓库插件/Web 构建流程；不要直接覆盖运行中的插件目录。

隐藏窗口或点击“暂停语音”会停止录音与朗读，保留文字订阅和已提交任务。回到窗口不会自动开麦，也不会补播旧回复；请点击“重新开启麦克风”恢复输入。“关闭朗读”独立控制语音输出，隐藏再显示不会覆盖手动静音；重新开启后仅朗读新一轮回复。通用循环使用 assistant-runtime 0.10.3 的输出开关。
