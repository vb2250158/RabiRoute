# io.rabiroute.manager.agent-communication

Built-in Manager plugin. Instance `manager:agent-communication` provides `manager.agent-communication@1`. Its implementation accesses host resources only through `@rabiroute/plugin-sdk` and versioned capabilities declared by the manifest.

Version `1.1.0` adds original-receipt reconciliation and cancellation through the existing delivery and state owners; capability majors remain `@1`.
