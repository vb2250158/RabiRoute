# 语音消息端

将麦克风转写接入消息路由，并通过共享语音服务合成和播放回复。此插件拥有路由中的语音配置卡片、消息端发现、转写订阅与语音回复外发。

在 WebGUI 左下角打开“插件”，可启用或停用“语音消息端”。语音识别、合成、模型和主机播放由独立的“语音服务”插件管理；该服务不可用时，本消息端显示等待依赖。

停用消息端会停止接收新的路由投递与语音外发，已接收的工作按原身份收尾。停用消息端不会关闭其他功能共用的识别、合成或模型服务。原始转写记录由共享语音服务保存；没有路由订阅的转写不会被当作已投递给 Agent。

本包通过原生插件发布 `endpoint.speech@1` 与 `endpoint.speech.egress@1`，依赖 `manager.speech@1` 和宿主通用消息端接口。宿主提供通用路由与资源端口，插件负责自己的订阅、配置界面和外发生命周期。
