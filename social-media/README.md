# 社媒素材工作区

[English](README_en.md) | 简体中文

本目录是 RabiRoute 对外内容（B站、抖音、知乎、公众号、小红书、linux.do、V2EX、掘金、少数派、X、HN、Reddit）的素材与文案工作区。

整个目录默认不进入版本库，原因见「忽略规则」。这里只保留中英文说明文件。

## 目录结构

| 目录 | 放什么 | 是否入库 |
| --- | --- | --- |
| `01-raw/screenshots/` | 未处理的截图原图，含真实界面 | 否 |
| `01-raw/recordings/` | 录屏原文件、手机拍屏、素材片段 | 否 |
| `02-final/video/` | 剪辑完成的视频（横屏长视频、竖屏切片） | 否 |
| `02-final/image/` | 成图、图文卡片、GIF | 否 |
| `02-final/cover/` | 各平台封面 | 否 |
| `03-copy/<平台>/` | 该平台的正文、标题、标签草稿 | 否（确认后可手动纳入） |
| `04-publish/` | 发布记录与数据回填（CSV） | 否 |
| `05-temp/` | 中间文件，可随时清空 | 否 |

## 命名规范

`<日期>-<平台>-<主题>-<版本>.<ext>`

例：

- `2026-11-21-douyin-commute-test-v1.mp4`
- `2026-11-26-bilibili-install-full-v2.mp4`
- `2026-12-02-v2ex-first-post.md`

版本从 `v1` 开始，改一次加一。不要用「最终版」「final2」这类命名。

## 素材状态

在 `04-publish/publish-log.csv` 里记录，字段与《Rabi 社媒运营排期表》保持一致：

`日期,平台,标题,链接,状态,播放/阅读,收藏/点赞,群新增,备注`

状态取值：`draft`（准备中）、`ready`（可发）、`published`（已发）、`reviewed`（已复盘）。

## 忽略规则

`.gitignore` 已排除本目录下除本文件外的全部内容：

```gitignore
/social-media/*
!/social-media/README.md
!/social-media/README_en.md
```

原因：

1. **隐私**：截图与录屏里会出现 QQ 号、昵称、本机绝对路径、内网地址，公开仓库不能有这些。
2. **体积**：视频原文件动辄几百 MB，不适合入库。
3. **噪声**：素材版本频繁变化，提交历史没有价值。

如果某个纯文本文案确认可以公开（例如已发布的公众号文章），用 `git add -f social-media/03-copy/<平台>/<文件>` 单独纳入，不要整体放开目录。

## 使用约定

1. 任何素材进入 `02-final/` 前，先按《Rabi 资料总览与素材索引》的脱敏清单过一遍。
2. `05-temp/` 每周清一次，不要囤。
3. 发布后的数据回填到 `04-publish/publish-log.csv`，72 小时一次、一周后一次。
4. 本目录只放素材与文案，不放代码；与 RabiRoute 源码的联动不在这里做。
