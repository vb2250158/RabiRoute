# 桌面语音助手

独立窗口配置对话模型、识别与播报服务，使用与 DSH 相同的语音循环和设置面板。用户开口时停止当前播报，文字回复继续完成。此入口尚未连接宿主工具。

## 使用

在此目录安装依赖并运行 `npm run build`，然后 `npm start`。需要 Node.js 24 和本机可用的 Electron；设置中的“设备”页可指定 Electron 路径。服务只监听本机。启动入口保存在本机数据目录的 `ready.json`；该链接包含访问凭据，请勿分享。

默认数据目录为当前用户的 `%LOCALAPPDATA%/RabiAssistant`；可通过 `ASSISTANT_DATA_DIR` 指定其他私有目录，`ASSISTANT_PORT` 指定端口。密钥使用 Windows 当前用户 DPAPI 加密保存，不会返回给网页。关闭网页不会停止已开启的音频；使用“停止语音”结束收音，使用“退出助手”释放资源并退出后台服务。

打开“设置 → 对话”，选择提供商并填写连接信息，点击“保存并刷新模型”后选择模型并保存。服务不提供模型列表时可手动填写；原始接口地址放在“高级连接设置”。“语音识别”和“语音播报”页分别设置对应服务；“设备”页选择麦克风和扬声器。

## WorkBuddy 国内版

在“语音识别”和“语音播报”页选择提供商、模型、模式和音色。“模型参数”按功能分组，可以搜索中文名称或参数 ID。无效数值在字段旁提示；不适用于当前模型或缺少前置条件的参数禁用并说明原因。火山参数覆盖及尚未接入项见 [能力契约](../../packages/desktop-voice-service/SPEECH_CAPABILITIES.md)。

此入口复用 DSH WorkBuddy 插件的本地兼容网关协议：`GET /v1/models`、`POST /v1/chat/completions`，流式响应使用 SSE。首先在现有 WorkBuddy 网关中登录国内账号并启动服务，再将该网关的地址和网关密钥填入此页。默认 18088 只是模板，以网关实际配置为准。

CodeBuddy CLI 的访问密钥与网关密钥不是同一项配置。本应用不导入 WorkBuddy 账号令牌，不会把其他提供商保存的密钥迁移到此连接。

DSH 宿主内直接使用 DSH 的提供商、模型目录和会话模型切换；不需要在语音助手中重复填写对话 API Key 或地址。切换也会更新 DSH 默认模型。

## 验证范围

已通过配置隔离、模型列表、共享语音生命周期、Windows DPAPI 与本机控制接口测试；真实设备完成流式 PCM 播放、取消后迟到音频拒收和 Windows Job 释放验证。内置浏览器使用虚构配置验证提供商、模型下拉、保存及 DSH 宿主模式。

WorkBuddy 的真实网关对话、火山真实 ASR/TTS 和实际声学打断仍需正确配置的服务与设备验收。界面测试数据不能作为真实模型调用证据。

### 设置草稿与导航

设置分为对话、语音识别、语音播报、设备和外观。提供商、模型、识别模式与参数先进入草稿，点击“保存设置”后生效；关闭时可继续编辑、放弃或保存并关闭。模型列表刷新、试听及麦克风测试需要当前草稿时，按钮明确标为“保存并…”。DSH 宿主模型选择仍即时更新默认模型，并在控件旁说明。

宿主通过 `previewSettings(patches)` 与 `saveSettingsBatch(patches)` 提供同一套校验及模型配置归并逻辑。预览不持久化、不停止语音；批量保存最多 64 个补丁，在一次存储提交中应用，禁止直接写配置档案。连接密钥按实际提供商和地址另行保存。界面区分未保存状态、配置缺项与连接中断。

### 首次使用与预览边界

DSH 插件自动读取当前 DSH 的提供商和模型，无需在助手里重复填写对话密钥。先选模型，发送一句文字并确认收到真实回复，再配置识别、音色和音频设备；服务目录为空或仅配置了默认模型名，不代表模型已经可调用。隔离测试环境必须实际加载所需提供商插件和凭据，不能用示例模型证明可用。

界面预览明确标注不能对话；设置窗口、示例模型和保存反馈同样保留该标识。预览禁用密钥输入、发送、语音启动与音频测试。首次配置按对话、识别、播报、设备逐项引导；参数默认值可先保留。
