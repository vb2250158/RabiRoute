# 桌面语音助手

独立窗口配置对话模型、识别与播报服务，使用与 DSH 相同的语音循环和设置面板。识别到用户首个有效文字时停止当前播报，文字回复继续完成。此入口支持联网搜索，其他宿主工具尚未连接。

## 播报与字幕

对话气泡和独立桌面字幕随实际播放进度亮起。火山双向流使用服务返回的中英文词级时间戳；OpenAI PCM 当前按句跟随，没有逐字时间戳。服务较晚返回时间戳时字幕会追上已播位置，不按文字生成速度假装播完。桌面浮层在“设置 → 外观 → 显示独立字幕”开启。

识别到首个有效文字后停止当前声音，已亮文字停在原处，剩余回复继续生成并保留。播放高亮只保存最近 16 条回复的运行状态；聊天历史仍由原来的本机加密存储保存。

执行工具前收尾当前语音片段，搜索完成后用新片段继续播报；真实逐字时间戳按文字偏移接回同一条消息。新片段恢复播放状态，旧片段迟到的字幕与结束事件不再影响它。打断仍只停止声音，文字和工具工作继续。

## 使用

在此目录安装依赖并运行 `npm run build`，然后 `npm start`。需要 Node.js 24.14 或更新版本和本机可用的 Electron；设置中的“设备”页可指定 Electron 路径。服务只监听本机。启动入口保存在本机数据目录的 `ready.json`；该链接包含访问凭据，请勿分享。

默认数据目录为当前用户的 `%LOCALAPPDATA%/RabiAssistant`；可通过 `ASSISTANT_DATA_DIR` 指定其他私有目录，`ASSISTANT_PORT` 指定端口。密钥使用 Windows 当前用户 DPAPI 加密保存，不会返回给网页。关闭网页不会停止已开启的音频；使用“停止语音”结束收音，使用“退出助手”释放资源并退出后台服务。

Windows 独立版可在“设置 → 设备”选择“手动或关键词唤醒”。在可信的本机启动环境设置 `ASSISTANT_RESIDENT_SPEECH_EXECUTABLE` 指向 RabiSpeech 运行程序，并把本地 FireRedASR2 配置保存到助手数据目录的 `resident-speech/config.json`。设置 `ASSISTANT_RESIDENT_SPEECH_MODEL_ROOT` 指向本机的模型根目录，其中包含 `asr/sherpa-onnx-kws`。如果运行程序、源码和依赖分开安装，通过 `ASSISTANT_RESIDENT_SPEECH_SERVICE_ROOT`、`ASSISTANT_RESIDENT_SPEECH_DEPS_ROOT` 和 `ASSISTANT_RESIDENT_SPEECH_PYTHON_HOME` 提供绝对路径。语音服务版本需要包含 `scripts/assistant_capture_host.py`。

打开“设置 → 对话”，选择提供商并填写连接信息，点击“保存并刷新模型”后选择模型并保存。服务不提供模型列表时可手动填写；原始接口地址放在“高级连接设置”。“语音识别”和“语音播报”页分别设置对应服务；“设备”页选择麦克风和扬声器。

“连接与测试 → 识别示例”使用随包附带的公开中文短句“今天天气怎么样？”，无需系统语音、PowerShell、Azure SDK 或联网下载。样本来自 Microsoft 官方 MIT 许可示例，来源和许可见 [诊断资源](assets/diagnostics/README.md)。它发送给当前选择的 ASR 服务，只有实际转写成功才通过；所选模型需要支持中文。样本缺失、损坏或识别失败时，完整测试仍分别检查对话模型和播报，语音链路标为未测试。正常麦克风识别不依赖此样本。

仅供开发的公开假数据与生成配方放在 `test/fixtures`；随应用使用的固定诊断音频放在 `assets/diagnostics`，保留来源、哈希与完整许可并显式声明包资源。应用测试及仓库 `npm test` 核对资源清单，排除私有输入，不按音频格式判断隐私。含个人信息的输入使用 Git 已忽略的目录或仓库外临时目录。

## WorkBuddy 国内版

在“设置 → 对话”选择“WorkBuddy 国内版 · 官方登录”，刷新模型后选择并保存。本机官方 CodeBuddy CLI 使用自己的国内账号登录；网页直接复用该登录，模型列表从官方 CLI 读取。对话使用所选模型，服务出错时在页面提示。

先安装官方 `@tencent-ai/codebuddy-code` 并完成国内账号登录。默认查找当前用户 npm 全局安装位置，可在启动助手时使用 `ASSISTANT_WORKBUDDY_CLI` 指定 CLI 文件、`ASSISTANT_WORKBUDDY_NODE` 指定 Node 可执行文件。路径配置保存在本机启动环境。也可在私有数据目录的 `host-options.json` 中设置 `workbuddyCli: { "node": "C:/path/to/node.exe", "entry": "C:/path/to/node_modules/@tencent-ai/codebuddy-code/bin/codebuddy" }`。对话与自动/手动模型列表共用此配置，环境变量优先。启动调用前检查官方包名和版本信息，安装缺损与登录/额度错误分别提示；取消会停止本轮无工具 CLI，并等待实际退出。WorkBuddy 与 CodeBuddy 同一账号的积分共享，套餐权益以[官方定价](https://www.codebuddy.cn/docs/workbuddy/Pricing)为准。

官方 CLI 以 print/stream-json 模式处理每轮输入，流式文字进入现有助手循环。应用在本机加密保存完整聊天记录，并恢复有界模型上下文，使用当前人设作为系统提示词；此对话入口的 CLI 工具关闭。CLI 的账号与认证数据由官方客户端管理。

在“语音识别”和“语音播报”页选择提供商、模型、模式和音色。“模型参数”按功能分组，可以搜索中文名称或参数 ID。无效数值在字段旁提示；不适用于当前模型或缺少前置条件的参数禁用并说明原因。火山参数覆盖及尚未接入项见 [能力契约](../../packages/desktop-voice-service/SPEECH_CAPABILITIES.md)。

已有“WorkBuddy 国内版”兼容网关连接继续保留原配置，使用 `GET /v1/models`、`POST /v1/chat/completions` 与 SSE。该连接需要网关地址及网关密钥，默认端口模板为 18088。已观察到的上游 `11128` 渠道拒绝需由服务方处理。

CodeBuddy CLI 的访问密钥与网关密钥不是同一项配置。本应用不导入 WorkBuddy 账号令牌，不会把其他提供商保存的密钥迁移到此连接。

DSH 宿主内直接使用 DSH 的提供商、模型目录和会话模型切换；不需要在语音助手中重复填写对话 API Key 或地址。切换也会更新 DSH 默认模型。

## 联网搜索

“设置 → 联网搜索”默认跟随当前对话模型。WorkBuddy 使用官方 CLI 的 WebSearch 和已有国内登录，搜索调用继续使用当前所选模型。普通对话进程保持关闭原生 CLI 工具；独立受限的搜索调用将真实 WebSearch 回执交回共享助手工具循环。独立版适配器将已观察到的原生搜索动作绑定到当前请求和已声明的只读搜索工具，正文隐藏原生标记；模型自行追加的观察不会存入上下文。实际执行和结果仍由共享循环及真实回执决定。只发送搜索问题，不发送整段聊天或语音识别附加信息。

OpenAI 官方接口通过 Responses 的 web_search 使用当前模型，是否支持及额度是否可用以实际接口回执为准。第三方兼容地址不会自动取得官方搜索能力。也可选择独立的 Tavily 搜索服务，密钥单独加密保存在本机；服务失败不会偷偷切换到其他提供商。

保存后点击“测试搜索”，查看进行状态、失败原因和可点击来源。助手查资料时在消息中显示搜索状态，来源随聊天记录保存。连接测试使用固定的公开文档问题，会消耗所选服务的额度；测试状态属于本次运行，重启后需重新测试，聊天里的来源仍保留。DSH 继续使用宿主原生工具、模型配置及联网搜索，不重复显示独立版搜索设置。

实现依据：[CodeBuddy CLI](https://www.codebuddy.cn/docs/cli/cli-reference)、[OpenAI 联网搜索](https://developers.openai.com/api/docs/guides/tools-web-search)、[Tavily Search](https://docs.tavily.com/documentation/api-reference/endpoint/search)。

### 设置草稿与导航

设置分为对话、语音识别、语音播报、设备和外观。提供商、模型、识别模式与参数先进入草稿，点击“保存设置”后生效；关闭时可继续编辑、放弃或保存并关闭。模型列表刷新、试听及麦克风测试需要当前草稿时，按钮明确标为“保存并…”。DSH 宿主模型选择仍即时更新默认模型，并在控件旁说明。

宿主通过 `previewSettings(patches)` 与 `saveSettingsBatch(patches)` 提供同一套校验及模型配置归并逻辑。预览不持久化、不停止语音；批量保存最多 64 个补丁，在一次存储提交中应用，禁止直接写配置档案。连接密钥按实际提供商和地址另行保存。界面区分未保存状态、配置缺项与连接中断。

### 首次使用与预览边界

DSH 插件自动读取当前 DSH 的提供商和模型，无需在助手里重复填写对话密钥。先选模型，发送一句文字并确认收到真实回复，再配置识别、音色和音频设备；服务目录为空或仅配置了默认模型名，不代表模型已经可调用。隔离测试环境必须实际加载所需提供商插件和凭据，不能用示例模型证明可用。

界面预览明确标注不能对话；设置窗口、示例模型和保存反馈同样保留该标识。预览禁用密钥输入、发送、语音启动与音频测试。首次配置按对话、识别、播报、设备逐项引导；参数默认值可先保留。

### 连接与测试

“设置 → 连接与测试”显示模型、识别、播报、麦克风和语音流程的当前配置、测试状态及时间。可分别测试，也可点击“运行完整测试”。完整测试使用随应用提供的固定示例语音，实际执行识别、模型回复与播报，并检查暂停、恢复和停止；麦克风另外录音三秒，仅在本机检查输入信号。播放结果以播放器结束事件确认，扬声器音量和听感由用户实际确认。

测试进行中显示当前步骤和进度；失败显示原因和重新配置入口。更换服务、模型、音色或密钥后，受影响的结果需要重新测试。测试记录保存在本机数据目录的 `checks.json`，刷新或重新启动后仍可查看。首页仅保留运行状态、对话和语音控制。

本机离线识别可在数据目录的 `host-options.json` 配置 `localAsr.python`、`localAsr.dependencies` 和 `localAsr.model` 三个绝对路径，重启后即可选择“本机 Whisper · 离线”。使用已安装的 faster-whisper、离线权重、CPU/int8、语音检测与重复结果过滤；此适配器不下载模型。音频经进程标准输入传递并在内存中处理。真实环境的回声与插话听感仍需指定麦克风、扬声器验收。

### 2026-11-15 界面与首次使用

首次使用自动打开引导，完成或关闭后通过宿主设置保存完成状态；刷新和重启后不重复弹出。配置、诊断及分项测试统一在“设置 → 连接与测试”，首页专注当前运行状态、对话与输入。输入框和语音控制保留在窗口内，历史消息独立滚动；查看历史时保留位置，以“回到最新回复”恢复跟随。

首页分别展示收音、识别、生成与实际播放状态；暂停麦克风后主按钮为“继续收音”。“停止本次播报”仅中断当前声音，文字继续生成；“播报静音”持续关闭后续播报。检测到句尾后自动提交语音，提交成功即移除临时转写；增量文字直接显示在对话中，不再提供“修改后发送”。助手名称可编辑，同名模型显示实际模型 ID；音色支持搜索、收藏和风格/情绪能力筛选，完整参数仍保留。

火山流式识别的示例测试通过原有 PCM 适配器发送固定 16kHz 单声道音频，不启用麦克风；完整测试仍单独检查本机麦克风。播放器回执和用户听感确认分开，用户可选择“我听到了”或“没有声音”。

说话过程的反馈随识别服务能力变化：流式识别只显示不断更新的文字，最终校正以正式消息呈现，不显示波形；整句识别等待出字期间显示设备实际 RMS 音量的滚动波形。波形样本仅在内存保留最多 48 个，不保存音频；暂停、过期数据和断线状态不制造动态波形。

此前 41 项回归测试通过；固定示例的火山识别、WorkBuddy 回复、播报结束及语音启停流程通过。固定样本产生连续中间结果并收敛为最终标点文本；示例中首个中间结果约 0.75 秒。真实播放器在模型仍生成时接受停止命令，文字随后继续完成，麦克风真实 RMS 数据已在窄屏波形界面验收。此结果不替代指定设备下的回声抑制和真人插话听感验收。

### 本机连接与访问恢复

首次使用请打开启动入口 `ready.json` 提供的完整链接。浏览器会按当前地址和端口记住访问凭据，之后可直接打开该地址；启动链接会强制加载当前页面，避免旧页面只改变地址片段却未更新。凭据只授予本机助手访问权，不是模型 API Key。

后台凭据单独使用当前 Windows 用户的 DPAPI 加密保存在本机数据目录的 `access.json`；正常重启保持不变。浏览器只保存当前助手的访问凭据，不保存模型密钥。失效页面提供重新连接入口，粘贴完整启动链接后连接；不会通过取消鉴权来恢复访问。需要撤销旧入口时，停止助手后删除本机私有的 `access.json`，重启会生成新入口，旧链接与浏览器凭据随即失效。

### 连续语音与自动提交

火山识别默认启用 800 毫秒静音判句。实时识别与二遍校正模式持续送音频，在服务返回确定句后自动提交；`vad_segment_duration` 仅影响语义分句，不能代替静音判停。原有配置可在“语音识别 → 模型参数 → 速度与分句”开启“句尾自动提交”。收音、生成文字和播放分别显示，声音被打断不取消文字任务。

连续识别诊断不发送 EOF，避免以结束录音掩盖持续收音中的判句故障。2026-11-15 使用同一条持续 PCM 连接、随应用提供的固定样本，连续两轮完成真实火山识别、自动提交、WorkBuddy 回复与 Windows 播报结束；两轮提交后临时转写均清空，收音保持开启。此证据不包含真人麦克风的声学回声与插话听感。

动态表达改动之前，共享 SDK 的 132 项测试及桌面服务/独立应用的 52 项测试通过。真实 Windows 播放器出声且 WorkBuddy 仍在生成时，固定语音样本触发开口打断，约 76 毫秒停止本地声音；原回复文字继续完成，下一句自动提交，仍使用同一条收音连接。普通回答优先自然语言流式输出；工具动作与明确要求的结构化回答保留原验证。播放端在缓冲区满时等待已排队音频消耗，传输随之暂停读取；停止会立即唤醒等待并拒绝迟到音频。

历史接口地址无效时，状态与设置页仍可读取并允许修正；真正启动语音时仍执行接口校验。反馈类型由纯能力元数据产生，读取设置不创建提供商连接。

### 语音设置与动态表达

语音识别参数由用户设置。语音播报将“用户播放偏好”“助手本次表达”和“工具集成能力”分开：选择提供商、模型、音色后，默认语速、音量等仍由用户控制；风格提示词、情绪标签/强度、临时语速与音调以能力标签呈现，不再要求用户逐项填写。完整目录列出参数归属、模型/音色限制与尚未接入的输出。

在“语音播报”勾选“让助手自动控制语气”并保存后，助手会尝试根据对话中的人设与当前情境，同时生成正文和本次语音表达。控制信息不会进入聊天正文或朗读；未指定或不支持的值使用默认表达，不改写保存的偏好。关闭后使用默认表达，已有固定语气可单独恢复默认。

豆包 2.0 的风格指令、部分音色的情绪标签/强度及临时语速/音调已接入；此接口没有已核验的多维情绪向量。官方 OpenAI 接口提供模型/音色目录、mini TTS 风格指令、速度与按句 PCM 流式播放；普通兼容地址保留基本配置，不据此宣称支持 OpenAI 扩展。OpenAI 识别仍是整句录音后转写。本机 Whisper 识别保留，不接入本地 TTS。

2026-11-15 真实 WorkBuddy、豆包 TTS 和 Windows 播放器已验证同轮生成的风格指令与临时语速进入请求并完成播放，收音保持开启，用户偏好未被改写。OpenAI 适配器通过请求与取消测试；原保存的 OpenAI 密钥在两个语音接口均返回 HTTP 401，尚未完成该账号的真实播放验收。能力归属与宿主接入方式见共享服务的 `SPEECH_CAPABILITIES.md`。

动态表达改动后，共享 SDK、桌面语音服务与独立应用共 195 项测试通过。开启动态语气的真实固定样本打断测试中，PCM 有效语音起点至停声约 40 毫秒；文字继续完成，下一句自动提交并播放，单条持续收音保持开启。此结果仍不替代真人麦克风的回声与插话听感验收。

### 独立字幕与锁定

在“设置 → 外观”勾选“显示独立字幕”并保存，即可打开桌面置顶字幕，不需要先开启语音。点击“测试桌面字幕”显示 3 秒测试文字，不调用模型或麦克风。窗口打开失败会显示错误；启动助手时恢复上次的字幕开关。

未锁定时，文字和空白处都能拖动，按钮保持可点击。锁定后禁止移动和缩放，只显示字幕文字，鼠标点击穿透；可在网页设置或托盘菜单解锁。结束语音保留已启用的字幕，退出助手才回收整个桌面进程。字幕、语音和设备测试复用同一进程，避免多份字幕与托盘。

修复了仅保存开关但未创建窗口，以及停止语音即销毁字幕的生命周期问题。新增字幕启动、共享生命周期、测试及窗口不可见重试回归；组合测试 199 项通过。真实鼠标拖动与最终锁定样式需与原生窗口状态验证分开记录。

选择播报模型后，模型旁直接列出“支持 Agent 使用的能力”，同时标明当前接口、模型、音色、输入/输出以及自动调用是否开启。标签与实际表达白名单核对；未知模型、非官方兼容地址、未选择音色和宿主未接入不会标成已可调用。情绪标签按当前音色列出，仍不提供手动输入 Agent 参数的表单。

### 消息语音详情与整页设置

点击“设置”进入整页，可用左侧分类切换；窄屏改为顶部分类。“返回对话”回到原对话，有未保存修改时可以继续编辑、放弃或保存。

语音消息旁的“⋯”打开“语音识别详情”：查看本句实际返回的情绪、程度、性别/年龄估计、评分，以及本句使用的模型、识别方式和已启用功能。勾选但未返回的项目明确显示“已请求，接口未返回”。数值评分保留四位小数，原始值可在“查看本次接口数据”展开。检测结果是模型估计，不能当作准确率或真实身份。

助手消息的“⋯”打开“语音播报详情”，分别显示 Agent 本次表达、实际发出的 TTS 参数和已发送文字，以及合成/播放/打断状态。未启动语音或已静音时也会说明原因。详情只在打开时读取；不会进入对话模型上下文，不记录请求头、凭据或音频，随聊天记录加密保存。聊天列表每次加载 100 条；每条最多保留最近 4 段播报请求，长内容会截断。

情绪、性别和年龄检测默认关闭。官方接口明确检测会启用 VAD 分句，但未承诺零额外耗时；公开价目没有明确保证这些开关与基础识别完全同价。2026-11-15 对同一固定样本交替测试各 3 次，开启情绪检测后的首字中位耗时为 598 ms（关闭 594 ms），最终结果为 3510 ms（关闭 3464 ms）；不能据此推断所有场景的性能或实际账单。开启全部检测的真实示例返回了附加字段，并完成自动提交、WorkBuddy 回复与 TTS 播放；固定 PCM 打断约 52 ms 停声，文字继续。此结果不替代真人麦克风验收。

### 对话历史与上下文恢复

网页版由本机服务保存会话：刷新、关闭网页再打开，或正常退出并重启，都恢复同一个会话及聊天记录。历史不因模型上下文达到上限而删除；列表默认加载最近 100 条，用“加载更早消息”继续查看。

聊天正文、语音详情和模型使用的历史以 AES-256-GCM 加密写入数据目录的 `conversation.sqlite`；密钥由 Windows 当前用户 DPAPI 保护。数据库一次事务保存确认完成的回复和对应模型上下文。流式正文每 500 毫秒保存一次检查点，正常结束立即保存；进程异常退出可能缺少最后一个检查点内的文字。恢复后未完成消息标明状态，不自动重发或继续播放。读取、解密或保存失败会报错，不悄悄新建空对话；同一目录只允许一个后台实例拥有存储。

当前 WorkBuddy 与兼容接口每轮携带最近 24 条、最多 64,000 字符的模型历史，较早记录仍完整保存在本机并可查看，不会自动全部送给模型。保留的历史就是本入口长期可返回的对话资料；本次没有另建独立记忆系统，也没有实现跨全部历史的自动检索。

点击首页“清除上下文”，核对提示后确认，才会清空本助手当前聊天记录及模型上下文，并结束语音；密钥与人设不变。处理中不能清除，旧页面对旧会话的迟到发送会被拒绝。DSH 由原生会话持久化和恢复，清除动作切换新的原生会话，不借用网页版数据库、不删除其他 DSH 会话。

### 宽屏设置

设置页按可用宽度分栏：对话模型与助手身份并排，识别连接与模型参数并排，播报的模型/音色与表达能力并排。常用模型、音色、试听和动态语气直接可见；音色搜索与收藏、默认语速/音量、完整能力和连接细节按需展开，保留原有设置与草稿校验。

顶部提供“全屏显示”，可用 Esc 退出。浏览器不允许网页全屏时会提示最大化窗口。设置页只保留当前分类的标题及返回按钮，保存操作固定在底部；窄屏自动改为单列。此次仅更新前端静态资源，无需重启后台，也不清空聊天或修改密钥。

播报页以等宽、对齐的“选择声音”和“语气与能力”两张卡片展示主要操作。“试听音色”为主要操作，默认语速、完整参数和更多播放设置统一在下方展开。能力标签可以点击：详情分别说明用途、使用条件、助手如何使用，以及官方来源和核对日期；按 Esc 或“关闭”返回原标签。不可用标签仍可查看原因，查看说明不会开启功能或修改设置。

能力说明依据火山双向流式 V3 参数文档及 OpenAI Speech API；当前可用范围仍由所选模型、音色与宿主策略决定。详情中将供应商参数范围与本工具的 Agent 限制分开说明；其他提供商优先显示其原目录说明，缺少说明时明确标为未提供，不套用另一家平台的能力。

### 首字确认后打断

从 2026-11-15 本轮修正起，原始收音起始、音量/VAD 以及空白或被过滤的识别结果不再打断声音。流式识别的首个非空有效转写到达后立即停声，最终句继续自动提交；整句模式必须等整句结果返回。之前记录的 PCM 起点至停声指标属于旧的开口打断策略，不作为本规则的验收。

217 项回归通过。真实火山 ASR/TTS 与 Windows 播放器使用固定示例语音注入：只有 VAD 起始、没有文字时播放继续；首个中间文字回调后发出停止请求并收到停止确认，文字继续完成，最终句自动交付，同一条收音连接保持开启。此验证不替代真人麦克风、回声与实际听感验收。

识别页将“识别能力”和“识别偏好”分开。情绪、性别、年龄、说话人、语种、语速与音量信息默认开启，敏感词过滤默认关闭；可逐项关闭或点击“全部启用”。新配置默认使用实时识别加二遍纠正。辅助上下文由程序从当前对话最近一条助手回复提供，建立识别连接时自动附带；不再要求手动填写上下文或返回格式。原始结果保存在对应语音消息的详情中。

语音消息的转写文字保持原样显示。实际返回的情绪、年龄/性别估计、说话人、语种、语速和音量等信息以本条消息的隐藏 `speechObservation` 提供给 Agent，并随成功对话的模型上下文加密保存，刷新和重启后仍可参考。没有返回的属性不补值，历史估计只描述对应语句；请求体、密钥和日志标识不进入模型上下文。
