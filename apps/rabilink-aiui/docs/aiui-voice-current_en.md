Repeated static-validation claims were followed by first-fragment-only speech, missing second turns and lost interim transcripts. Comparing the current [official speech API](https://github.com/yodaos-project/AIUI/blob/main/skills/aiui-dev/references/apis/ai.md) with this implementation:

- `synthesize()` accepts the complete text of that invocation; later model fragments cannot be appended to the same task. Queue complete prose segments independently and flush an unpunctuated tail when generation completes. Neither submit just the first fragment nor delay all ordinary prose until the stream ends.
- Shared `speechSynthesis.cancel()` and utterance lifecycle events are not exposed. Cancellation, subtitles and completion use `synthesize()`, `SpeechAudioPlayer` and its underlying player events. Task `finished` means synthesis finished; timers detect failures. Neither proves successful playback.
- User onset stops playback while preserving current ASR, text, model and dispatched work. Do not destroy a sentinel recognizer and start another after onset, potentially losing the user's opening audio. A fixed 1500ms interruption exclusion does not establish echo cancellation or anytime interruption; acoustics still require device testing.
- `interimResults` requests a capability rather than guaranteeing support across hosts. The adapter consults `getCapabilities()` when present. Without that API, one generic `network` error does not justify repeatedly toggling configuration. Interim display and final instructions remain separate.
- Reproduced and fixed premature sentence splitting after a chunk-ending dot: `3.` + `14`, `example.` + `com`, and `v1.` + `2` stay together. Added `؟`, `؛`, `۔`, `।`, and `॥` terminators. This is punctuation segmentation, not universal abbreviation/semantic detection or evidence of matching host voices.
- Ordinary prose can stream into sentence playback. Strict JSON actions/final replies still release text only after complete validation and never speak protocol fields. This path still incurs first-audio latency; segmentation tests do not prove its removal. Cues drive subtitle updates; GPT-like realtime acoustic acceptance remains incomplete.
