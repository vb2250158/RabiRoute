# 助手与语音宿主分层

人格、工具决策、语音交互和远端传输不能各自创建一份助手循环。共享实现位于 `packages/assistant-runtime`，接口见该包的 `VOICE_HOST_CONTRACT.md`。

| 层 | 唯一职责 | 当前实现 |
| --- | --- | --- |
| 助手 | 全局提示词、人格、模型推理、工具决策、固定目标与原始回执 | `assistant-session.js` 或宿主原生 Agent/Session；原拥有者保留持久输入及历史 |
| 语音交互 | 收音重启、用户输入优先、只停 TTS、流式切句、串行播放、旧回调隔离 | `voice-interaction.js`；注入 ASR/TTS 资源 |
| 工具连接 | 发现和调用接口、鉴权、传输、持久幂等与结果核对 | 产品适配器；新的远端连接最后实现 |

眼镜页面通过 `ensureVoiceInteraction()` 创建唯一语音 owner，`beginVoiceResponse()` 将助手文字增量接入该 owner。Web 模拟器运行同一份编译页面和共享代码，只替换宿主能力。DSH 使用自己的有日志 Session 作为助手层时，不能再套一层工具执行循环；其 GUI 和可选桌宠订阅同一语音 owner。Rabi 桌宠也应作为助手视图，不能因为打开桌宠再启动一份麦克风或模型。

用户开口会停止当前音频及排队音频，旧回答文字仍可继续，已派发的工具不会取消。新输入由助手层保存并决定引导、插话或后续轮次；语音模块的接收布尔值不是持久回执。暂停收音、关闭页面、停止播音和取消工作是不同动作。

VAD 的 `speechstart/speechend` 描述实际说话状态，分段 ASR `final` 只描述识别结果；不能用分段 final 推断用户已停止说话。文字模拟模式在提交完整输入前结束模拟 onset；真实麦克风仍由其 VAD 产生结束事件。合成完成也不等于播放完成，只有播放器结束事件确认播放结束。中断时资源 owner 显式停止播放器再销毁。

## 验证范围

0.10.2 共享测试 103 项、严格 TypeScript 消费检查、编译页面的 48 项原生合同测试通过。Web Ink 0.19.1 回归验证连续回复、开口即停声、保留模型流与识别会话、后续回复、停止后重新打开。Web 输入和音频是测试夹具，未证明真实麦克风、回声消除或眼镜扬声器效果。

Rabi 桌面已接入独立 `io.rabiroute.manager.voice-assistant` 插件，`/voice-assistant` 页面与桌宠菜单共用该入口。它沿用原生角色 Agent，浏览器只做 PCM/ASR 适配，RabiSpeech 保持唯一播放队列。按原始输入 ID、角色和路由归属接收回复；每段 TTS 使用独立取消会话，取消不会误停其它声音。退出页面释放语音，原生任务继续。麦克风状态与助手任务状态分别显示，权限超时可以重试。

Rabi 候选通过完整前后端类型检查、WebGUI 构建、17 项适配回归、24 项消息/语音接口回归和真实 outbox 时间线关联测试。内置浏览器夹具完成两轮输入，第二轮仅取消对应播放会话，文字保留。桌宠 Python 修改完成语法检查；实际 Qt、麦克风、模型/工具和正式安装尚未验收。

DSH 维护对话报告独立 GUI 候选构建及 19 项测试通过，仍待私有 Git 来源授权、隔离安装和真实语音验收。不得把 SDK 或组件测试写成两个桌面产品已交付。新的远端工具连接仍最后实现。
