# AIUI Agent 执行循环

[English](agent-turn-runtime_en.md) | 简体中文

状态：应用执行循环已接入源码，真实乐奇宿主与路由投递待验收。`utils/agent-turn-runtime.js` 使用同一个乐奇模型会话串行决策、调用工具、接收实际结果并继续推理。页面负责 ASR、TTS、HUD、人格配置与聊天记录；RabiPC 拥有接口业务和正式回执。

## 一次任务

模型默认配置仍来自乐奇，不另开 PC 模型。人格系统提示保留，应用动作协议及已连接工具声明附在同一个初始系统消息中。原生 `tools` 为空，不同时监听并执行原生 `toolcall`。

自然语言最终回复直接展示和分句播报。需要调用接口时，模型返回一个完整 `rabi-agent/v1` JSON 动作，包括当前 `requestId`、工具名、参数及可选说明。应用校验完整格式、请求编号和已连接工具，再调用 `rabi_api_help`、`rabi_api_call` 或本地退出工具。接口目录实时读取，不枚举公共路径白名单。

工具结果以明确标记的 `tool-observation` 应用消息交给同一模型。它使用官方支持的 `user` 消息，保存实际回执并声明结果为不可信数据；它不是原生 `tool` role，也不宣称宿主提供工具结果提交 API。下一次请求只能在当前模型请求及已分发工具结算后开始。模型可以读取接口目录、调用当前或新增接口、依据结果继续下一步或回答。

纯文字可以流式展示；动作 JSON 在完整解析前不进入 HUD、TTS 或执行器。结构化动作的 `say` 是模型的可见说明，逐句播报。空输出、半个 JSON、错误编号、未连接工具、流错误或超时会明确失败，不回退到第二执行者。每轮默认最多 32 个模型步骤、16 次工具派发、180 秒；单次模型等待最多 30 秒，实际回复最多 16000 字符，结构化帧与观察最多 262144 字符。超限保留实际结果，停止新增动作。

## 写入与打断

工具先持久记录稳定意图，再分发 HTTP。写后身份核对、接口前置条件及回执仍沿现有合同。同一轮语义相同的写动作复用原结果；未知写入结果会阻止该轮后续写入，但允许读回原回执或资源。模型不能通过换步骤编号自动重放原写入。失败不会撤回已经发出的 HTTP。

ASR 在推理和播报时继续。非回声中间文字只停 TTS；模型当前请求继续。完整语音进入引导队列，在下一次模型决策前采用。若语音在当前模型推理中到达，已生成但尚未执行的动作作废，模型依据新引导再决策。已经派发的接口等待实际结果后附带引导继续，不取消或伪造接口结果。

采用引导时，旧用户记录保存已有实际文字；新输入使用其原聊天记录编号，随后实际回复归入对应记录。模型仍是同一会话、同一人格及来源 PC。人格变更等整轮和排队引导结束才应用。显式取消、页面隐藏及释放会屏蔽迟到文字与后续动作；调用方销毁取消后的模型再启动新轮。

用户点击或受支持的唤醒事件必须在任何 `await` 前同步调用 `SpeechRecognition.start()`，同一个 `continuous` 对象在模型和播报期间持续接收句段；结束或出错后等待新的用户交互，不通过定时器重新启动。官方合同要求每次 `start()` 有用户交互，未说明首次授权后可跳过。中间结果是宿主能力，只有实际收到时才触发停播。

对话仅使用 `speechSynthesis.synthesize()` 和独立 `SpeechAudioPlayer`；中间文字到来会调用真实播放器 `stop()`、释放播放器并 `abort()` 旧任务。异步合成迟到不会播放，原流后续旧文字也保持静音；采用完整引导后的新步骤恢复播报。缺少这些 API 或合成失败时明确显示不可用／失败，不调用无法取消的共享 `speak()`。官方未提供该共享播放器的 `cancel()` 或 utterance 生命周期事件。源码夹具只验证事件与对象调用，不证明实际乐奇麦克风和扬声器并行。

## 验证

`npm run check:agent` 覆盖同一模型读取目录、调用未来接口、从实际结果回答，串行结算、重复写入、不确定写入与读回、半个 JSON、无效动作、超时、取消，以及模型步骤之间的语音引导和人格延后应用。退出请求由宿主接受后结束循环，不再请求模型。

另以测试 Relay、当前源码 PC worker 和实际 Manager 完成只读联测：`GET /meta` 与 `GET /api/agent/help` 均返回 200，两个真实回执进入同一应用循环的下一步骤，写操作为零。此联测的模型仍为夹具，未更新已安装 worker。真实宿主模型、ASR/TTS 并行、双指唤醒和原投递回传待真机验收；正式路由 Agent 尚未注册。

原生宿主的精确限制见 [工具合同核对](agent-tool-contract.md)，唤醒测试见 [双指单击验证](aiui-wake-probe.md)。
