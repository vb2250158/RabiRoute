# 设备 Agent 配置应用

[English](agent-profile-runtime_en.md) | 简体中文

状态：源码已接线，隔离测试、本机 AIX 测试包构建及解析核验已执行；最新集成回归按验收矩阵记录。尚未正式安装或真机验收，测试包不能作为已验收运行版本。

页面启动时仍先读取启动参数与旧 `rabilink_lingzhu_agent` 设置；旧记录保留不删除。只有取得已保存的真实设备凭据，才恢复独立 `rabilink-aiui-agent-profile-v1` 缓存并请求当前设备配置。设备 profile 优先于旧参数/名称设置；启用后口语改名提示改用手机，避免两个来源争抢。缓存按 Relay 地址、设备 SN 与不透明凭据指纹隔离，不包含原始凭据。归属变化清除当前 profile、待应用项和远端回执；忙轮结束后释放旧模型。迟到的读取及回执按 scope 与请求代际丢弃，不能把旧人格确认给新账号。

启动、设备首次领取凭据、既有手动刷新及 HUD“点击刷新配置”触发一次 GET `/api/rabilink/device/agent-profile`，不增加轮询。无设备凭据不请求，普通应用 Token 不冒充设备身份。当前轮执行期间仅暂存新 profile，不销毁模型；轮结束后保存，下一轮创建新模型。存储失败保留旧模型与配置，提示失败。

Skill 指引用受限 schema 和 `buildAgentSystemInstructions` 组合进模型提示。模型创建成功后才向 `/api/rabilink/device/agent-profile/applied` 报告版本；回执不确认则显示待核对，手动刷新先读权威状态。稳定回执键按版本/状态固定；提交前后读取权威状态，历史幂等回执不能当成当前状态。启用 MCP 引用但尚未装入当前模型时，首次应用报告 `failed/TOOLS_UNAVAILABLE`；失败后可以转为成功。同版本已经成功应用后不再降级，服务拒绝降级为 `409 PROFILE_ALREADY_APPLIED`，临时工具故障只在本地提示，不消耗新的操作回执。旧存量若历史成功回执与当前失败状态不一致，显示未确认并要求手机重新保存配置，不自动迁移或生成随机键。

此处 applied 是该版本一次成功应用的记录，不是当前工具在线健康。它只证明本页面模型配置创建完成，不证明工具调用闭环、平台智能体 ID 绑定或真实设备语音验收。官方未公布的工具结果回传 API 不能用普通 prompt 模拟。
