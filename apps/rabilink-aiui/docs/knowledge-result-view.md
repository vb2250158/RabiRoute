# 眼镜知识结果阅读

[English](knowledge-result-view_en.md) | 简体中文

查询默认只播报短摘要，不自动长篇朗读记录，也不把工具结果作为模型新指令或自动续轮输入。查询成功后可明确说“读出工具结果”，再说“下一条工具结果”逐段阅读；模型仍在回答时会提示稍后操作。正文使用现有回复区域，页码在状态行，纯文本展示。

只有成功且非不确定的结构化回执可以读取。提取已知记录字段（标识、标题、焦点、正文、详情等），最多 20 条记录、12000 个 Unicode 码点；每页最多 50 个视觉预算单位（常见中文计 2，ASCII 计 1）。分页不把正常笔记里的 HTML 字样或指令文字删成空白，它们仍只是资料，不会被执行。缺少可展示字段时提示无可展示正文，不冒称查询为空。

结果与设备归属和明确选择的角色绑定，切换后不再可读；原始模型文字保持不变，HUD 只使用有界显示副本。记录需要更多详情或超过限额时，使用 PC 端查看原始记录。当前仅本机模拟测试，未构成真机或自动模型续轮验收。
