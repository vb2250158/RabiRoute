# AIUI 模型执行归属

[English](agent-runtime-mode_en.md) | 简体中文

默认 `local-aiui`：用户语音只交给页面的宿主 `LanguageModel`。领取设备凭据、保存手机配置或连接 PC 不改变执行归属。PC 通过独立受控 HTTP 提供工具，不替代眼镜模型。

默认模式不将新语音加入旧远端推理队列，不发送旧语音队列、不调用远端审阅、不启动旧 Agent 消息长等待，也不播报旧远端回复队列，避免双投与双回复。现有旧队列保留，不删除用户记录。设备状态、配置读取和运行日志仍沿原合同工作。

兼容旧远端观察端时，必须在页面启动参数中显式传入 `agentRuntimeMode=legacy-remote-observer`。旧 `mode=transcription` / `configuration` 只选择页面操作状态，不隐式选择推理 owner。显式兼容模式只向远端发送语音，不同时调用本地模型；缺少真实凭据时显示未连接，不静默降级到另一执行者。仍使用原受控前台长等待，不新增轮询。

该兼容入口保留用于既有远端消息端调用者迁移。新 AIUI 使用默认本地模式；当旧调用者均迁移且旧队列经用户确认处理完成后，方可移除兼容入口。测试覆盖真实凭据仍默认本地、显式远端、互斥投递及旧队列发送/播报入口的模式门禁；不等于真机或 MCP 工具结果续轮验收。
