# 工具等待期间的语音输入

Rabi 页面使用共享助手 SDK 0.7.2 的逐条 `interject` 接口。已有工具等待回执时，新完整语音先写入设备本地记录并读回确认，再提交给同一个乐奇宿主模型；模型请求仍串行。插话格式仅随独立输入请求发送，不放在每轮共用提示中。当前模型尚未派发工具时的语音修正仍走原 steering 流程，不伪装成独立任务回执。

独立输入沿用自己的原话、稳定编号、原聊天记录 ticket 和任务 scope。模型明确回答时，答案先保存到该条记录，再请求字幕展示和 TTS；它不进入原工具任务的文字或历史。需要工具的输入只保留原话，等待原轮结束后以原编号重新决策；不执行先前模型提议的缓存动作。

`defer` 可附带非空、最多 16000 字符的说明，解析后丢弃，不播报、不保存为答案，也不作为完成或执行回执。协议、请求与输入编号以及字段集合仍严格校验。

每条输入捕获原 profile、连接 scope、设备 owner、API runtime 和模型代次。新一轮执行前与每次模型/工具边界复核；连接变化、隐藏或销毁后不能转给新任务。新语音到达后，较早插话答案仍可保存，但不能重新抢占字幕或启动播报。停播不撤销已派发的后台操作。

## 本地记录与恢复

`aiui-input-ledger.js` 是待处理独立输入的拥有者，使用官方 `wx.getStorageSync/setStorageSync`。聊天历史和 PC 工具回执各自保留原拥有者，不用聊天记录冒充任务结算。记录不包含凭据；存储失败、读回不一致或损坏数据会停止该输入提交。

- `submitted` 表示预留后准备/尝试模型提交；`running` 表示已预留后续正常执行。进程中断后两者转为 `unconfirmed`，不重放。
- `deferred` 或尚未提交的 `retained` 只在原活跃页面、原绑定仍有效时排队。页面重建后不会按新连接自动执行。
- `answered` 只证明该条答案已生成并本地保存；`completed` 只证明该条助手轮结束。两者均不证明眼镜已经显示、用户已经听见或所有后台工作结束。
- 本地最多 64 条记录。新增时仅移除最旧已 answered/completed 的缓存；未完成记录不被挤掉，容量不足会拒绝新输入并显示原话。

重新启动时显示待核对数量与最后一条原话。点击底部“↑ 记录”，或在对话模式按上方向键，可以逐条查看原话、保存的答案和处理状态。左右换条、上下翻页，确认键或返回键关闭；长文本分为每页两行，原始内容不截断。读取失败显示错误并保留查看入口。

记录视图只从 ledger 读取快照，不执行恢复转换、不提交模型、不停止现有收音或推理。新记录不会抢走正在查看的条目，结果保存后刷新原条目。页面隐藏时关闭视图；重开仍可读取持久记录。这里没有重试或“标为完成”按钮：手动复述输入不是安全的原任务重试，已经发生的工具操作须核对原后端回执，不能因本地未确认而重做。

## 验证范围

17 项页面引导/本地记录测试覆盖独立历史、延后重审、稳定 ID、存储失败、旧答案抑制、连接切换、重新读取、未知结果不重放与容量，以及只读浏览、完整 Unicode/多行翻页、实时结果更新和错误清除。38 项编译页面合同含等待工具期间生成语音、按原 ID 执行延后输入、清理后迟到结果不复活、重建读取原话，以及浏览按键不打断任务或收音；输入、模型、存储与语音资源仍为夹具。

实际 Ink 记录视图使用隔离内存记录夹具检查 480×352 与 448×150 窗口的打开、翻页、换条和返回；不是眼镜存储验收。[官方真实模型诊断](tool-wait-probe.md)已通过等待期间回答、延后新工具请求和原轮结束后执行；工具、转写与存储均为夹具。真实设备存储、真人 ASR/TTS 和声学双工仍需验收。
