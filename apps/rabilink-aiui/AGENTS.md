# Agent: RabiLink AIUI (Universal On-Device Master Agent)

> **受控轮询例外**：AIUI QuickJS 没有原生 SSE/WS/分块回调。为保证前台主动下行和 backlog，允许在连接远端时保留受控长等待；在页面隐藏、退出或断线时立即停止，不做高频空请求。单机本地主控模式下完全不依赖网络轮询。

- **Version**: 1.0.23
- **Description**: Rokid AR 眼镜端通用主控智能体与消息端框架，单一 Agent 模式，全面支持设置与绑定灵珠智能体。
- **Author**: RabiLink Project

## 架构定位与解耦声明

RabiLink AIUI 是一个**通用的眼镜端主控智能体（Universal On-Device Master Agent）框架**，核心设计理念为**单一 Agent 模式**并与特定人格彻底解耦：
- **与特定人格彻底解耦**：本框架不绑定任何特定角色（包括夜雨或其他预设人格）。用户想绑定什么智能体都行——面向 Rokid 灵珠智能体生态，既可作为本地通用助手，也可绑定任意灵珠智能体（Lingzhu Agent）。
- **统一单一模式（Agent 模式）**：彻底告别割裂的双模式切换，整个应用统一为一个纯粹的 **Agent 模式**。用户戴上眼镜即是与智能体面对面交流，所有日常对话、灵珠智能体设置与控制指令均在 Agent 模式内统一由大模型理解并闭环执行。
- **支持设置灵珠智能体**：支持通过页面参数（`agentId`、`agentName`、`systemPrompt`）、本地持久化存储，或直接通过口语指令（“设置灵珠智能体为 xxx”）动态切换绑定的智能体名称与人设。
- **零 Token 本地独立闭环**：无需配置 Token、无需手机扫码或绑定 PC，戴上眼镜即可开箱即用，由端侧原生 ASR、原生系统端侧大模型（SLM）与原生 TTS 实现纯本地对话闭环。
- **开放多智能体协同**：配置远端连接后，可无缝接入任意外部智能体大脑（如灵珠平台云端智能体、RabiRoute、Codex、DSH 或自定义后端），作为双向观察感知端与主动消息呈现端。
- **插件精简**：不需要额外导入 RabiLinkMessage MCP 或独立插件，输入事件、主动消息与配置接口均由端侧页面与标准协议覆盖。

## System Prompts

你是运行在 Rokid AR 眼镜上的灵珠主控智能体（Lingzhu Master Agent）。你面向用户的 AR 透视视野，提供自然流畅的语音交互与极简 HUD 视觉辅助。

- 默认使用简洁自然的中文与用户对话，表达清晰、聚焦，适合眼镜端语音播报。
- 遵循 AR 视觉原则：字幕与状态简短明确，避免长篇大论遮挡现实世界。
- 在未连接远端时，以绑定的灵珠智能体身份直接与用户交流并辅助完成设备调控；在连接远端时，可靠同步用户环境观察，并准确播报远端智能体的回复与主动关怀。
- 绝不主动索取、明文记录或复述用户的密码、Token 及其他私密凭证。

## Capabilities

- **AIUI `SpeechRecognition`**：前台连续自然语言采集，状态机受控续轮，具备快速重复文本与标点抑制。
- **AIUI `LanguageModel`**：Rokid 系统端侧原生大语言模型，零参数纯净会话契约，支持流式对话生成与白名单工具调用。
- **AIUI `speechSynthesis`**：Rokid 原生语音合成（甜美女声），流式分句播报，生命周期与文本时长双重超时监控。
- **智能打断与回声消除（Barge-in）**：严格过滤自身 TTS 回声与毫秒级重复输入；仅当检测到真人新发话时立即中断当前播报并开启新一轮应答。
- **极简 AR HUD 渲染**：底部 20px 大字号复古绿高对比度半透明字幕，顶部状态胶囊（动态灵珠智能体名称、状态 Pill、时钟、电量），中央视野 100% 通透。
- **动态灵珠智能体配置**：支持设置和记忆 `agentId`、`agentName` 与 `systemPrompt`，支持口语指令切换智能体。
- **可选远端协同（HTTP Relay / API）**：双向无阻塞队列、统一观察账本同步、持久游标消息消费与主动消息接收。

## 统一 Agent 模式与兼容调用规则

同一个 `pages/home/index` 页面承载全部功能，对内统摄为单一 Agent 模式，同时兼容历史页面工具调用：
1. **统一 Agent 对话与主控**：
   - 用户打开即进入 Agent 模式；未配置 Token 时作为本地主控闭环运行（`SpeechRecognition` 采集 -> 本地 `LanguageModel` 流式生成 -> 原生 TTS 播报）；
   - 配置 Token 后，自动激活远端协同：眼镜 ASR 观察追加到远端统一账本，同时通过持久游标流接收并播报远端 Agent 的普通回复与主动消息。
2. **支持设置灵珠智能体**：
   - 启动参数支持传入 `agentId`、`agentName` 和 `systemPrompt`；
   - 运行时直接说“设置灵珠智能体为 xxx”或“绑定智能体 xxx”，系统立即完成设置并语音确认。
3. **兼容模式路由**：
   - 若外部旧智能体以 `mode=transcription` 调起（连接对话）或以 `mode=configuration` 调起（配置助手），页面在**同一个 AIUI 页面内切换**并无缝承接；模式切换只改变内部状态，禁止调用页面结束方法或 `finish()`，严禁退出页面。

## 页面与交互合同

- `pages/home/index` 为唯一产品页面，单页面内承载完整交互，不进行页面重定向或多页面跳转。
- **视觉层级**：HUD 采用单绿色调（#00FF88 / #55FF99）与高对比度透明背景，顶部显示当前绑定的灵珠智能体名称，底部 20px 大字号字幕确保 AR 强光与暗光下的极佳可读性。
- **手势交互**：
  - 单击触摸板（Tap）：在播报时打断当前 TTS；在远端模式空闲时请求远端 Agent 即时审阅。
  - 双击触摸板（Double Tap）：返回上一级或退出当前应用。
- **麦克风交接**：TTS 播报开始前立即释放 ASR 麦克风占用；播报结束后自动恢复下一轮 ASR，避免眼镜自己听自己说话。
